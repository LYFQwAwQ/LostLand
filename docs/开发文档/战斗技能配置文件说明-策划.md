# 战斗技能配置文件说明（策划）

> 目标：让策划在不改代码的情况下，直接通过配置文件完成技能新增、删除、改数值、改持续时间、改附加状态。

## 1. 配置文件位置

- 文件：`src/data/battleSkills.config.json`
- 编码：`UTF-8`
- 格式：标准 JSON（不支持注释、末尾逗号）

## 2. 顶层结构

```json
{
  "defaultActiveSkillId": "basic_attack",
  "activeSkills": [],
  "passiveSkills": [],
  "talents": []
}
```

- `defaultActiveSkillId`
  - 含义：保底主动技能 ID（单位无可用技能时会使用它）。
- `activeSkills`
  - 含义：主动技能列表（可造成伤害/治疗，并可附带额外效果）。
- `passiveSkills`
  - 含义：被动技能列表（只提供属性修正）。
- `talents`
  - 含义：天赋列表（带稀有度与属性修正）。

## 3. 主动技能字段（`activeSkills[]`）

### 3.1 必填字段

- `id`：技能唯一 ID（只能英文/数字/下划线，不能重复）
- `name`：技能名
- `skillPool`：`common | class | enemy`
- `category`：`assault | defend | inspire | afflict | succor`
- `description`：描述
- `targetType`：`self | singleEnemy | allEnemies | singleAlly | allAllies | lowestHpAlly`
- `effect`：`damage | heal`
- `mpCost`：法力消耗（整数）
- `cooldown`：冷却回合（整数）
- `baseWeight`：AI 基础权重
- `basePower`：技能基础值
- `scaling`：属性系数对象（见下）

### 3.2 常用可选字段

- `allowedHeroClasses`：`["paladin"]`、`["mage"]`、`["paladin","mage"]`、`[]`
- `damageType`：仅 `effect=damage` 时生效，`physical | magic`
- `element`：`fire/water/ice/wind/life/light/undead/dark`
- `canCrit`：是否可暴击（布尔）
- `conflictSkillIds`：冲突技能 ID 列表（不能共存）
- `selfStatus` / `targetStatus`：直接附加状态（见 5 节）
- `weightTuning`：动态权重修正（低血线、敌人数等）
- `extraEffects`：扩展效果（护盾/净化/驱散/推拉条/附加状态，见 6 节）

### 3.3 `scaling` 子字段

- `str`
- `int`
- `def`
- `maxHp`
- `missingHp`

示例：

```json
"scaling": { "int": 0.85, "maxHp": 0.02 }
```

## 4. 被动与天赋字段

### 4.1 `passiveSkills[]`

- 必填：`id/name/skillPool/description/modifiers`
- 常用可选：`allowedHeroClasses/conflictSkillIds`

### 4.2 `talents[]`

- 必填：`id/name/rarity/skillPool/description/modifiers`
- `rarity`：`common | rare | epic | legendary | unique`
- 常用可选：`allowedHeroClasses/conflictSkillIds`

### 4.3 `modifiers` 结构

```json
"modifiers": {
  "flat": { "maxHp": 420, "def": 38 },
  "ratio": { "damageReduction": 0.06 },
  "elementBoost": { "light": 0.12 },
  "elementRes": { "dark": 0.08 }
}
```

- `flat`：直接加值
- `ratio`：比例修正
- `elementBoost`：元素增伤
- `elementRes`：元素抗性

## 5. 状态配置（`selfStatus/targetStatus`）

```json
"targetStatus": {
  "key": "burning",
  "chance": 0.4,
  "duration": 2,
  "potency": 0.04
}
```

- `key` 可用值：
  - `frozen`（冻结）
  - `stunned`（眩晕）
  - `poisoned`（中毒）
  - `burning`（灼烧）
  - `guarded`（守护）
  - `weakened`（虚弱）
  - `shielded`（护盾）
  - `immune`（负面免疫）
  - `taunted`（嘲讽）
- `chance`：触发概率（0~1）
- `duration`：持续回合
- `potency`：强度（可选，不填走默认）

## 6. `extraEffects`（重点）

`extraEffects` 是数组，可叠加多个效果，按数组顺序执行。

### 6.1 `applyStatus`

```json
{
  "type": "applyStatus",
  "target": "targets",
  "application": { "key": "taunted", "chance": 1, "duration": 2 }
}
```

### 6.2 `shield`

```json
{
  "type": "shield",
  "target": "self",
  "duration": 2,
  "basePower": 140,
  "scaling": { "def": 0.6 }
}
```

### 6.3 `cleanse`（净化）

```json
{
  "type": "cleanse",
  "target": "targets",
  "removeCount": 2,
  "polarity": "negative"
}
```

### 6.4 `dispel`（驱散）

```json
{
  "type": "dispel",
  "target": "targets",
  "removeCount": 2,
  "polarity": "positive"
}
```

### 6.5 `actionDelta`

```json
{
  "type": "actionDelta",
  "target": "targets",
  "delta": -500
}
```

- `target`：`self | targets`
- `polarity`：`positive | negative | all`

## 7. 常见操作

### 7.1 新增技能

1. 在对应数组新增一个对象（主动/被动/天赋）。
2. 保证 `id` 唯一。
3. 若是主动技能，至少填完 3.1 的必填字段。
4. 如需加状态或净化/驱散，补 `selfStatus/targetStatus/extraEffects`。
5. 在英雄默认模板或技能槽位配置中引用该 `id`（如需默认上阵）。

### 7.2 删除技能

1. 从数组删除该技能对象。
2. 同步删除所有引用该 ID 的默认槽位配置（避免空引用）。

### 7.3 调整数值

- 伤害/治疗：`basePower + scaling`
- 释放频率：`mpCost/cooldown/baseWeight`
- 状态时长：`duration`
- 状态概率：`chance`
- 护盾量：`extraEffects[type=shield].basePower/scaling`

## 8. 常见错误与排查

- 问题：页面报 JSON 解析错误
  - 原因：有注释、末尾逗号、引号不匹配。
- 问题：技能不生效
  - 原因：`id` 重复或引用 ID 拼写错误。
- 问题：技能出现但行为不对
  - 原因：`targetType/effect/damageType` 组合不合理，或 `extraEffects` 字段名写错。
- 问题：状态没挂上
  - 原因：`chance=0`、`duration<=0`，或目标当前有 `immune` 且该状态属于负面。

## 9. 建议流程

1. 先复制一个现有技能对象改名。
2. 一次只改一个目标（比如先只调 CD）。
3. 每次改完都跑一场战斗看日志与复盘状态页。
4. 大改前备份一份 JSON。
