# 战斗技能配置文件说明（策划）

> 目标：让策划在不改代码的情况下，直接通过配置文件完成技能新增、删除、改数值、改持续时间、改附加状态。

## 1. 配置文件位置

- 目录：`src/data/battleSkills/`
- 编码：`UTF-8`
- 格式：标准 JSON（不支持注释、末尾逗号）

## 2. 目录结构（固定）

第一层目录（按你的业务分类）：

- `common`
- `paladin`
- `mage`
- `enemy-normal`
- `enemy-elite`
- `enemy-boss`
- `enemy-common`

每个第一层目录内的文件：

- 主动技能五分类：
  - `assault.json`
  - `defend.json`
  - `inspire.json`
  - `afflict.json`
  - `succor.json`
- 被动与天赋：
  - `passives.json`
  - `talents.json`

另外：

- `common/meta.json`
  - 用于配置 `defaultActiveSkillId`（保底主动技能）。
- 重要约束：
  - 除 `meta.json` 外，其余文件内容必须是数组 `[]`，即使只有一个技能也要写成 `[ { ... } ]`。

## 3. 文件内容结构

### 3.1 主动技能分类文件（如 `paladin/assault.json`）

```json
[{
  "id": "paladin_holy_blade",
  "name": "圣辉斩",
  "rarity": "epic",
  "skillPool": "class",
  "category": "assault",
  "description": "附带光元素的高伤害斩击。",
  "targetType": "singleEnemy",
  "effect": "damage",
  "damageType": "physical",
  "element": "light",
  "mpCost": 22,
  "cooldown": 3,
  "baseWeight": 125,
  "basePower": 132,
  "scaling": { "str": 0.9, "int": 0.2 }
}]
```

### 3.2 被动文件（如 `mage/passives.json`）

```json
[{
  "id": "passive_arcane_flow",
  "name": "奥术潮汐",
  "rarity": "rare",
  "skillPool": "class",
  "allowedHeroClasses": ["mage"],
  "description": "提升法力和法术强度。",
  "modifiers": {
    "flat": { "maxMp": 240, "int": 25, "elementalPierce": 0.05 }
  }
}]
```

### 3.3 天赋文件（如 `enemy-common/talents.json`）

```json
[{
  "id": "talent_enemy_predator",
  "name": "掠食本能",
  "rarity": "common",
  "skillPool": "enemy",
  "description": "提升敌方攻击倾向。",
  "modifiers": { "ratio": { "damageBoost": 0.06 } }
}]
```

### 3.4 元数据文件（`common/meta.json`）

```json
{
  "defaultActiveSkillId": "basic_attack"
}
```

## 4. 主动技能字段（`*.json` 五分类文件里的对象）

### 4.1 必填字段

- `id`：技能唯一 ID（只能英文/数字/下划线，不能重复）
- `name`：技能名
- `skillPool`：`common | class | enemy`
- `category`：`assault | defend | inspire | afflict | succor`
- `description`：描述
- `targetType`：`self | singleEnemy | allEnemies | singleAlly | allAllies | lowestHpAlly`
- `effect`：`damage | heal`
- `mpCost`：法力消耗（整数）
- `cooldown`：冷却回合（整数）
- `baseWeight`：AI 基础权重
- `basePower`：技能基础值
- `scaling`：属性系数对象（见下）

### 4.2 常用可选字段

- `rarity`：`common | rare | epic | legendary`（玩家可用主动技能建议必填）
- `allowedHeroClasses`：`["paladin"]`、`["mage"]`、`["paladin","mage"]`、`[]`
- `damageType`：仅 `effect=damage` 时生效，`physical | magic`
- `element`：`fire/water/ice/wind/life/light/undead/dark`
- `canCrit`：是否可暴击（布尔）
- `conflictSkillIds`：冲突技能 ID 列表（不能共存）
- `selfStatus` / `targetStatus`：直接附加状态（见 6 节）
- `weightTuning`：动态权重修正（低血线、敌人数等）
- `extraEffects`：扩展效果（护盾/净化/驱散/推拉条/附加状态，见 7 节）

### 4.3 `scaling` 子字段

- `str`
- `int`
- `def`
- `maxHp`
- `missingHp`

示例：

```json
"scaling": { "int": 0.85, "maxHp": 0.02 }
```

## 5. 被动与天赋字段

### 5.1 `passives.json`

- 必填：`id/name/skillPool/description/modifiers`
- 常用可选：`rarity/allowedHeroClasses/conflictSkillIds`
- `rarity`：`common | rare | epic | legendary`（玩家可用被动技能建议必填）

### 5.2 `talents.json`

- 必填：`id/name/rarity/skillPool/description/modifiers`
- `rarity`：`common | rare | epic | legendary | unique`
- 常用可选：`allowedHeroClasses/conflictSkillIds`

### 5.3 `modifiers` 结构

```json
"modifiers": {
  "flat": { "maxHp": 420, "def": 38 },
  "ratio": { "damageReduction": 0.06 },
  "elementBoost": { "light": 0.12 },
  "elementRes": { "dark": 0.08 }
}
```

- `flat`：直接加值
- `ratio`：比例修正
- `elementBoost`：元素增伤
- `elementRes`：元素抗性

## 6. 状态配置（`selfStatus/targetStatus`）

```json
"targetStatus": {
  "key": "burning",
  "chance": 0.4,
  "duration": 2,
  "potency": 0.04
}
```

- `key` 可用值：
  - `frozen`（冻结）
  - `stunned`（眩晕）
  - `poisoned`（中毒）
  - `burning`（灼烧）
  - `guarded`（守护）
  - `weakened`（虚弱）
  - `shielded`（护盾）
  - `immune`（负面免疫）
  - `taunted`（嘲讽）
- `chance`：触发概率（0~1）
- `duration`：持续回合
- `potency`：强度（可选，不填走默认）

## 7. `extraEffects`（重点）

`extraEffects` 是数组，可叠加多个效果，按数组顺序执行。

### 7.1 `applyStatus`

```json
{
  "type": "applyStatus",
  "target": "targets",
  "application": { "key": "taunted", "chance": 1, "duration": 2 }
}
```

### 7.2 `shield`

```json
{
  "type": "shield",
  "target": "self",
  "duration": 2,
  "basePower": 140,
  "scaling": { "def": 0.6 }
}
```

### 7.3 `cleanse`（净化）

```json
{
  "type": "cleanse",
  "target": "targets",
  "removeCount": 2,
  "polarity": "negative"
}
```

### 7.4 `dispel`（驱散）

```json
{
  "type": "dispel",
  "target": "targets",
  "removeCount": 2,
  "polarity": "positive"
}
```

### 7.5 `actionDelta`

```json
{
  "type": "actionDelta",
  "target": "targets",
  "delta": -500
}
```

- `target`：`self | targets`
- `polarity`：`positive | negative | all`

## 8. 常见操作

### 8.1 新增技能

1. 先判断归属目录（`common/paladin/mage/enemy-*`）。
2. 主动技能放到对应分类文件（`assault/defend/inspire/afflict/succor`）。
3. 被动和天赋分别放 `passives.json`、`talents.json`。
4. 保证 `id` 唯一。
5. 若是主动技能，至少填完 4.1 的必填字段。
6. 如需加状态或净化/驱散，补 `selfStatus/targetStatus/extraEffects`。
7. 在英雄默认模板或技能槽位配置中引用该 `id`（如需默认上阵）。

### 8.2 删除技能

1. 从对应目录/分类文件删除该技能对象。
2. 同步删除所有引用该 ID 的默认槽位配置（避免空引用）。

### 8.3 调整数值

- 伤害/治疗：`basePower + scaling`
- 释放频率：`mpCost/cooldown/baseWeight`
- 状态时长：`duration`
- 状态概率：`chance`
- 护盾量：`extraEffects[type=shield].basePower/scaling`

### 8.4 调整技能稀有度（随机英雄相关）

- 主动/被动技能稀有度由技能配置中的 `rarity` 决定。
- 随机英雄抽技能时会按 `heroGeneration.json -> randomSkillRarityWeights`（默认 80% 普通 / 19% 稀有 / 1% 史诗）优先命中对应稀有度池。
- 若某次抽样目标稀有度在当前候选池为空，系统会自动回退到其余可选技能。

## 9. 常见错误与排查

- 问题：页面报 JSON 解析错误
  - 原因：有注释、末尾逗号、引号不匹配。
- 问题：技能不生效
  - 原因：`id` 重复、引用 ID 拼写错误，或放错目录文件。
- 问题：技能出现但行为不对
  - 原因：`targetType/effect/damageType` 组合不合理，或 `extraEffects` 字段名写错。
- 问题：状态没挂上
  - 原因：`chance=0`、`duration<=0`，或目标当前有 `immune` 且该状态属于负面。

## 10. 建议流程

1. 先复制一个现有技能对象改名。
2. 一次只改一个目标（比如先只调 CD）。
3. 每次改完都跑一场战斗看日志与复盘状态页。
4. 大改前备份一份 JSON。
