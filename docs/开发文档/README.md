# LostLand 开发文档总览

本目录用于给后续开发者提供统一入口，目标是快速理解项目结构、模块边界和配置修改方式。

## 1. 快速上手（建议顺序）

1. 先看流程规范：`00-开发主指导.md`
2. 安装依赖并启动项目
   ```bash
   npm install
   npm run dev
   ```
3. 读 `01-项目与目录总览.md`，理解入口和目录分层。
4. 再读地图主链路：
   `02-地图生成与月度结算模块.md` + `05-状态管理与数据模块.md`。
5. 需要改功能页时读：
   `03-节点交互模块.md`、`04-英雄与队伍模块.md`。
   组织基地相关改动同时参考：`01-项目与目录总览.md`、`05-状态管理与数据模块.md`、`06-UI与样式模块.md`。
6. 需要改样式时读：
   `06-UI与样式模块.md`。
7. 需要改战斗系统时读：
   `07-战斗系统模块.md`。
8. 需要调整数值时读：
   `配置文件修改指南.md`。

## 3. 新开发者建议阅读路径（30 分钟）

1. 先跑起来，看 `世界地图 -> 节点 -> 功能页` 的完整跳转。
2. 用浏览器打开以下文件并并排阅读：
   - `src/main.tsx`
   - `src/App.tsx`
   - `src/state/MapSystemProvider.tsx`
   - `src/pages/WorldMapPage.tsx`
3. 再根据任务类型进入对应模块文档，避免在 `styles.css` 或页面文件中盲改。

## 4. 文档维护约定

- 每次新增核心模块（新 page / 新 lib / 新 state）时，至少更新：
  - 本文件索引；
  - 对应模块文档中的“关键文件”列表。
- 每次改动工程配置（脚本、构建、TS 配置、路由模式）时，更新：
  - `配置文件修改指南.md`。
