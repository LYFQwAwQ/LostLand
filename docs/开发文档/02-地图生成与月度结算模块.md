# 02. 地图生成与月度结算模块

## 1. 模块职责

- 生成每个 Region 的节点与连线拓扑。
- 进行每月一次的节点演化结算（秩序场/扩张场）。
- 输出本月事件和可视化回放步骤数据。

## 2. 关键文件

- `src/lib/topology.ts`
  - 负责地图生成：
    - 泊松盘采样点生成
    - Delaunay 三角化（Bowyer-Watson）
    - 基于最小生成树 + 剪枝保留连通边
- `src/lib/monthlySimulation.ts`
  - 负责月结算：
    - 全图节点影响力传播
    - 阈值触发节点进化/退化
    - 计算地图压制值
    - 产出 `RegionMonthReport`
- `src/lib/archetypes.ts`
  - 定义 ST/BL/NOD 各类型基础参数（初始强度、场强倍率等）
- `src/lib/fieldVisual.ts`
  - 场强视觉映射（节点光环、连线颜色/线宽）

## 3. 数据流（结算主链路）

1. 用户在地图页点击“结算下一个游戏月”。
2. `MapSystemProvider.advanceOneMonth()` 调用 `settleRegionOneMonth(region)`。
3. `monthlySimulation.ts`：
   - 基于边权构建全图最短路距离矩阵；
   - 计算每个节点收到的总秩序/扩张影响；
   - 处理状态变化（激活、幽灵、混沌化、净化、升级/降级）；
   - 生成本月事件与回放帧。
4. Provider 回写新 region，并更新左侧日志。

## 4. 常见修改任务

## 4.1 调整地图“复杂度”

修改 `src/data/mockData.ts` 中 `buildRegionTopology` 入参：

- `basePointCount`：节点数量
- `minDistance`：点间最小距离
- `complexity`：边保留复杂度
- `maxRadius`：影响传播半径

## 4.2 调整演化平衡

优先修改：

- `src/lib/archetypes.ts`：各 archetype 的 `initialStrength` / `orderScale` / `expansionScale`
- `src/lib/monthlySimulation.ts`：阈值条件（如 `negativeMonths >= 2`）

建议每次只改一类参数并观察 5-10 月演化结果，避免多个变量叠加导致无法定位问题。

## 4.3 调整地图压制值计算

修改 `monthlySimulation.ts` 的 `mapSuppression()`：

- 稳定区与混沌区权重
- 繁荣度对压制值的影响上限
- 最终 clamp 范围（0-100）

## 5. 注意事项

- 结算函数是纯“输入 region -> 输出新 region”，不要在页面组件里直接改节点对象。
- 节点/边视觉只读 `field` 与 `fieldFlux`，不要在样式层写死颜色逻辑。
- 回放帧依赖 `RegionMonthReport.playback`，如果新增步骤要同步更新地图页播放栏逻辑。
