# 02. 地图生成与月度结算模块

## 1. 模块范围

本模块覆盖以下内容：

1. 大陆 / 疆域 / 地区选择
2. 地区懒加载
3. 地区拓扑生成（节点、边、初始状态）
4. 月度结算与回放
5. 场强可视化与测距
6. 地区级布告栏任务初始化

不包含：节点功能页细节、战斗细节、英雄配置。

## 2. 主调用链

### 2.1 地区选择到地图生成

`src/config/world/worldHierarchy.json`
-> `src/data/worldMapData.ts`
-> `WorldMapPage` 解析 URL 选择
-> `MapSystemProvider.ensureRegionLoaded(regionId)`
-> `createRegionTopologyById(regionId)`
-> 固定地区：`src/data/fixedRegionTopologies.ts`
-> 其他地区：`src/lib/topology.ts`
-> 页面渲染地区地图

### 2.2 月结算

`WorldMapPage` 点击“结算当前地区下一个游戏月”
-> `MapSystemProvider.advanceOneMonth(regionId)`
-> `settleRegionOneMonth(region)`
-> 更新地区节点、地图压制、月报、世界日志
-> `WorldMapPage` 播放回放帧

## 3. 关键文件

| 文件 | 作用 | 什么时候改 |

## 4. 世界地图页面当前职责

### 4.1 URL 与选择状态

- 使用 `useSearchParams` 维护 `continent` / `dominion` / `region`
- 兼容旧参数写法：只有 `region` 时会尝试补全选择
- 第一章期间会强制锁定到章节目标地区（来自 `OrganizationProvider.chapterTargetRegionId`）
- 章节主线完成后解除锁定，恢复正常地图切换

### 4.2 地区选择弹窗

- 第一层：大陆 -> 疆域
- 第二层：疆域 -> 地区
- 地区弹窗使用 `worldHierarchy.json` 的 `pickerPosition` 或自动布局
- 第一章未完成时弹窗入口禁用，并显示统一锁定文案

### 4.3 地图主画布

- 显示节点、边、场强层、节点标签
- 支持点击节点进入节点页
- 支持迷雾节点查看雾化进度
- 支持测距模式与最短路径高亮
- 支持空白区域拖拽平移与“快速回中”按钮
- 地图内容运行在放大画布上（用于拉开点位密度，减少节点堆叠）

### 4.4 月报回放

- 数据来自 `region.lastMonthReport.playback`
- 支持播放关键帧，突出高亮 / 不稳定 / 状态变化节点

## 5. 地区生成规则入口

### 5.1 结构配置在 `worldHierarchy.json`

这个文件决定：

1. 大陆列表
2. 每个大陆有哪些疆域
3. 每个疆域有哪些地区
4. 地区邻接关系
5. 每个地区的 seed 和地区选择弹窗坐标

### 5.2 生成参数在 `worldMapData.ts`

`createRegionTopologyById` 会把疆域配置转成地区生成参数，例如：

- 基础规模
- 复杂度
- faction 权重
- 初始强场数量
- 初始预演化月数
- 边权范围

同时包含固定拓扑分流逻辑：

1. 若地区命中 `hasFixedRegionTopology(regionId)`，直接走 `createFixedRegionTopology(...)`。
2. 未命中固定拓扑的地区，继续走原随机生成 `buildRegionTopology(...)`。

这保证了旧随机系统代码仍保留，但当前可用地图优先接入固定地图。

### 5.3 拓扑算法在 `topology.ts`

这里负责：

1. 采样点生成
2. 德劳内三角化与裁边
3. 节点 archetype / faction / 初始 simulation 状态
4. 初始地图压制值估算

改地图形状时，优先改这里，而不是在页面里硬调坐标。

## 6. 月结算规则入口

`src/lib/monthlySimulation.ts` 负责：

1. 计算节点间 Order / Expansion 影响
2. 更新 faction 倾向
3. 推进节点 active / inactive / ghost 状态
4. 更新 field visual
5. 重新计算边流量和地图压制
6. 生成 `RegionMonthReport`
7. 生成回放帧 `playback`

如果你要改“哪个节点会衰退 / 扩张 / 变迷雾 / 变幽灵”，直接看这个文件。

补充（地区压制值系统）：

- `MapSystemProvider` 维护玩家治理带来的压制增量（战斗胜利、任务提交），并在月结算结果上叠加。
- 压制值满值（100）触发地区“完全解放态”：清除活跃 `BL1`，地区不再保留最高级不稳定节点。

## 7. 与任务系统的关系

地区首次加载时：

- `MapSystemProvider.ensureRegionLoaded` 会同时生成该地区的布告栏任务。
- 任务生成依赖该地区实际节点与敌人/掉落可用性。

所以：

1. 改地区节点 archetype，会影响可生成的任务类型。
2. 改敌人或掉落池，也会间接影响任务可用性和警告信息。

## 8. 常见改动怎么找文件

| 需求 | 文件 |
| --- | --- |
| 新增地区 / 调整邻接 | `src/config/world/worldHierarchy.json` |
| 调整地区规模和节点密度 | `src/data/worldMapData.ts` `src/lib/topology.ts` |
| 调整月结算强度 / 状态阈值 | `src/lib/monthlySimulation.ts` |
| 调整地图场强颜色和线条 | `src/lib/fieldVisual.ts` `src/styles.css` |
| 改地区弹窗布局或开放策略 | `src/pages/WorldMapPage.tsx` |
| 改世界日志格式 | `src/state/MapSystemProvider.tsx` |

## 9. 当前限制与注意事项

1. 地区是懒加载的，只在第一次进入时生成并缓存。
2. 当前月份推进是“只结算当前地区”，不是全世界同步推进。
3. 第一章期间地图切换受章节门禁控制，仅开放章节目标地区；主线完成后恢复正常切换。
4. 页面显示依赖 Provider 中缓存的地区对象，不要在页面里重新生成地区。
5. 固定地图节点支持 `entityType` 与 `battleConfig`：
   - `entityType`：用于前台显示“地名 + 类型”，替代 ST/BL 模板编码直接展示。
   - `battleConfig.enemyPool` + `countDistribution`：用于节点固定敌人池与战斗人数分布抽样。
6. 当前人族疆域已扩展为 6 个固定地区，并按“离流明城越远越无序、越危险”重配：
   - 邻接与选区：`worldHierarchy.json` 新增 `silvergrain-meadows` 与 `blightfang-outerreach`，并重排邻接图形成距离梯度。
   - 稳定/无序比例：`radiant-coastline`（近）到 `blightfang-outerreach`（远）逐级提升无序占比。
   - 战斗难度上限：近区（流明城周边）限制在 `BL2` 上限；远区恢复/提升 `BL1` 节点比例。
7. 世界地图显示层新增“拖拽浏览大画布”能力：
   - 页面参数 `MAP_CANVAS_SCALE` 控制画布放大倍率。
   - `map-pan-canvas` 通过指针拖动更新偏移，`map-center-btn` 可一键回中。
8. 拖拽偏移边界依赖 `map-stage` 的实际尺寸：
   - `WorldMapPage` 的尺寸监听需要在地区加载后重新绑定（建议依赖 `region?.id`）。
   - 若 `stageSize` 维持在 `0`，`panOffset` 会被 clamp 为 `0`，表现为地图无法拖动。
   - 低兼容环境缺少 `ResizeObserver` 时，至少要保留 `window.resize` 兜底更新尺寸。
