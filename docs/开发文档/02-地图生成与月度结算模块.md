# 02. 地图生成与月度结算模块

## 1. 模块职责

- 按 `大陆 -> 疆域 -> 地区 -> 节点` 四层结构组织世界地图数据。
- 在“进入地区”时懒生成该地区拓扑与初始演化状态。
- 在“地区选择弹窗”中展示同疆域地区拓扑（地区点 + 虚线连接）。
- 地图区内“邻接快捷切换”只允许同疆域且存在弹窗连接关系的地区。
- 进行每月一次的节点演化结算（秩序场/扩张场）。
- 输出本月事件和可视化回放步骤数据。

## 2. 关键文件

- `src/config/world/worldHierarchy.json`
  - 世界静态配置（大陆、疆域、地区、邻接关系、疆域参数）。
- `src/data/worldMapData.ts`
  - 读取并校验 JSON 配置。
  - 提供多层查询 API（大陆/疆域/地区/邻接）。
  - 将疆域参数转换为 `buildRegionTopology` 入参。
- `src/lib/topology.ts`
  - 负责地区初始化：
    - 泊松盘采样 + Delaunay 三角化 + 复杂度修剪；
    - K1 静态锚点分配（Cradle）；
    - 完整势力概率保底（缺失势力补 Hub）；
    - 预生长模拟 + 历史扰动（Prosperity ±10%）。
- `src/lib/monthlySimulation.ts`
  - 负责月结算：
    - 全图节点影响力传播；
    - 阈值触发节点进化/退化；
    - 计算地图压制值；
    - 产出 `RegionMonthReport`。
- `src/state/MapSystemProvider.tsx`
  - 地区懒加载与缓存。
  - `advanceOneMonth(regionId)` 当前地区月结算入口。

## 3. 数据流（结算主链路）

1. 地图页从 URL 读取 `continent/dominion/region`。
2. `MapSystemProvider.ensureRegionLoaded(regionId)` 懒生成地区（首次进入）。
3. 用户点击“结算当前地区下一个游戏月”。
4. `MapSystemProvider.advanceOneMonth(regionId)` 调用 `settleRegionOneMonth(region)`。
5. Provider 回写该地区新快照，并更新左侧日志。

## 4. 常见修改任务

## 4.1 调整世界层级和邻接

修改 `src/config/world/worldHierarchy.json`：

- `continents[].dominionIds`
- `dominions[].regionIds`
- `regions[].neighbors`
- 中央大陆当前示例已扩充为每个疆域 5 个地区（用于观察非全互邻拓扑效果）。

## 4.2 调整地区初始化规模/复杂度

优先修改 `worldHierarchy.json` 的疆域字段：

- `baseRegionScale` + `scaleRange`：节点规模
- `complexityBase` + `complexitySwing`：连线复杂度
- `pathWeightRange`：边权扰动区间
- `maxRadius`：场传播半径

## 4.3 调整势力撒点与预生长

优先修改 `worldHierarchy.json`：

- `factionWeights`
- `initialStrongFieldCount`
- `fullFactionChance`
- `initEvolutionMonthCap`
- `weightSwing`

## 4.4 调整演化平衡

优先修改：

- `src/lib/archetypes.ts`：各 archetype 的 `initialStrength` / `orderScale` / `expansionScale`
- `src/lib/monthlySimulation.ts`：阈值条件（如 `negativeMonths >= 2`）

建议每次只改一类参数并观察 5-10 月演化结果，避免多个变量叠加导致无法定位问题。

## 5. 注意事项

- 结算函数是纯“输入 region -> 输出新 region”，不要在页面组件里直接改节点对象。
- 多层世界入口已改为 URL 三参数：`continent`、`dominion`、`region`；新页面跳转请带齐参数。
- 当前测试阶段临时限制：`WorldMapPage` 仅开放中央大陆（`central`）入口，其他大陆按钮置灰且手动 URL 会被回写到中央大陆。
- 当前版本只结算“当前地区”，不是全世界批量结算（后续计划见项目 TODO）。
- 回放帧依赖 `RegionMonthReport.playback`，如果新增步骤要同步更新地图页播放栏逻辑。
