# 06. UI 与样式模块

## 1. 模块职责

- 统一管理页面视觉风格、布局和组件样式。
- 提供地图页的节点/连线/回放高亮等可视化表现。

## 2. 关键文件

- `src/styles.css`
  - 全局唯一主样式文件（当前约 1900+ 行）
- `src/components/layout/MainLayout.tsx`
  - 左右分栏主布局对应样式入口
- `src/pages/WorldMapPage.tsx`
  - 地图节点 class 组合和 CSS 变量驱动
- `src/pages/InventoryPage.tsx`
  - 背包页（装备缩略展示 + 半透明详情弹窗）
- `src/pages/OrganizationPage.tsx`
  - 组织基地原型页（40x40 网格建造、战争迷雾 + 升级扩张、占地高亮、缩放平移、功能建筑占位弹窗）

## 3. 当前样式组织方式

- 主题变量定义在 `:root`（颜色、边框、文本等）。
- 以页面和模块 class 分段组织：
  - 布局：`app-shell` / `left-panel` / `main-panel`
  - 地图：`map-*` 前缀
  - 英雄：`hero-*` 前缀
  - 背包：`inventory-*` 前缀
  - 组织系统：`organization-*` 前缀
  - 节点页模块：`module-*` / `action-*`

## 4. 常见修改任务

## 4.1 全局主题换色

优先修改 `:root` 的变量：

- `--bg`
- `--panel`
- `--card`
- `--line`
- `--text`
- `--muted`
- `--gold`

不要先改散落的十六进制颜色，避免后续维护困难。

## 4.2 调整地图节点视觉

节点视觉由两层共同决定：

1. `src/lib/fieldVisual.ts` 输出视觉参数（透明度、缩放、连线颜色）
2. `src/styles.css` 负责实际表现样式

建议先调 `fieldVisual.ts` 的计算参数，再微调 CSS。

## 4.3 调整响应式布局

统一在 `src/styles.css` 的媒体查询区域修改，避免在页面组件内写内联样式兜底。

## 4.4 调整背包装备展示

- 装备卡片网格：`inventory-grid`
- 装备详情弹窗：`inventory-modal-backdrop` / `inventory-detail-modal`
- 品质/品阶颜色：`quality-*` / `rank-*`
- 内部分数分档颜色（不展示分数）：`tier-low` ~ `tier-mythic`
- 筛选与排序栏：`inventory-toolbar`
- 可组合标签筛选条：`inventory-tag-groups` / `inventory-tag-chip`
- 详情主信息融合区：`inventory-detail-meta-list`（品质/品阶/插槽，等级在标题行）
- 标签分组折叠：`inventory-tag-group` / `inventory-tag-group-toggle`（默认展开品质与品阶，部位折叠）
- 品质文案采用名称制（普通/优秀/稀有/史诗/传说/神话），颜色仅作视觉标记
- 详情面板去框化：`inventory-detail-block` 采用虚线分割，不再使用块状边框
- 品质/品阶/插槽信息融入标题附近：`inventory-header-meta`
- 具体类型行融合品质标签：`inventory-subtype-line`（示例：法袍 · 传说）
- 同模块属性列表取消行内分割线，改为更紧凑排版：`inventory-detail-list p`

## 4.5 调整组织基地界面

- 顶部标题区 + 横向评级卡：`organization-page-header` / `organization-rank-inline`
- 三栏布局：左侧选中建筑、中央地图、右侧建筑面板与编辑控制
  - `organization-left-rail` / `organization-stage-card` / `organization-right-rail`
- 建筑候选列表：`organization-building-list` / `organization-building-item`
- 地图与视口：`organization-viewport` / `organization-grid` / `organization-cell`
- 地块状态：`organization-cell.revealed`（已开发草地区）/ `organization-cell.fogged`（战争迷雾区）
- 配色约束：草地使用偏淡纯绿、战争迷雾使用纯灰，避免金属质感或渐变修饰
- 交互捷径：组织地图在建造模式下右键可快速切换到平移模式（`onContextMenu`）
- 扩张交互：组织升级后获得扩张次数，切换 `扩张地块模式` 点击地图可扩展一块 `7x7` 地块（可配置，需在现有领地外、与现有领地相邻、且不能相交）
- 视觉规则：非扩张模式下，领地外区域保持纯灰背景且不显示明显网格；进入扩张模式后才显示外圈网格
- 预览规则：扩张模式下仅当鼠标位于“现有领地外”时才显示整块扩张范围（`preview-ok/preview-bad`）；鼠标位于领地内不显示扩张预览
- 样式优先级：扩张预览色（`preview-ok/preview-bad`）优先级高于扩张灰格底色，避免范围预览被灰色覆盖
- 平移规则：平移模式下地块层透传鼠标事件，仅建筑标签可拦截点击；因此除建筑本体外可在任意地图位置拖拽平移
- 性能策略：组织地图采用“视口可见区域裁剪渲染”（仅渲染当前可见范围内格子），降低大地图模式下的 DOM 数量与重绘开销
- 相机规则：`复位视角` 以“当前已拥有地块包围盒中心”为目标居中；滚轮与按钮缩放按锚点重算偏移，避免缩放时视角飘移
- 状态反馈：`organization-feedback`、`preview-ok`、`preview-bad`、`selected`
- 建筑浮层与占位弹窗：`organization-hover-card` / `organization-modal`
- 滚轮行为：`organization-viewport` 使用 `overscroll-behavior: contain`，页面容器使用 `overscroll-behavior: none`，避免地图缩放时外层面板同步滚动
- 响应式断点：
  - `max-width: 1480px`：改为“上方信息卡 + 下方地图”两行结构
  - `max-width: 900px`：侧栏改单列、工具栏改竖向

## 5. 注意事项

- 页面中的 class 组合较多（如地图节点高亮/不稳定/变更态），删改 class 前要先确认回放功能是否依赖。
- 若拆分 `styles.css` 为多文件，建议先按页面拆分（map/hero/node/layout）再逐步迁移，避免一次性大改带来回归风险。
