# 07. 战斗系统模块

## 1. 模块范围

本模块覆盖：

1. 战斗入口与战斗页
2. 我方 / 敌方战斗模板组装
3. 实时战斗引擎
4. 掉落生成
5. 战斗回放与复盘视图
6. 战斗结果对背包和任务的回写

## 2. 主调用链

`NodeActionPage`
-> `BattlePage`
-> `HeroRosterProvider` / `BattleSetupProvider` / `EquipmentInventoryProvider`
-> `buildAllyTeamTemplates` / `buildEnemyTeamTemplates` / `buildFixedEnemyTeamTemplates`
-> `createBattleRuntime`
-> `stepBattle`
-> `endBattle / finalizeBattle`
-> `grantBattleHeroExp`
-> `collectBattleDrops`
-> `reportMissionBattleOutcome`

## 4. BattlePage 当前职责
### 4.1 进入战斗前

- 用 `nodeId` 找到当前地区和节点
- 从 `HeroRosterProvider`、`BattleSetupProvider`、`EquipmentInventoryProvider` 组装我方战斗模板
- 通过 `battleUnits.ts` 生成敌方队伍
- 若 URL 带 `ritualId`，则切换到仪式战模式并改用固定 Boss 阵容

### 4.2 战斗进行中

- `setInterval(..., 16)` 驱动 `stepBattle`
- 支持开始 / 暂停 / 强制结束 / 重置本场 / 重新侦察
- 支持 1x / 2x / 3x 倍速
- 右侧战斗日志优先显示连战累计日志，空时回退到当前日志
- 右侧日志区固定高度滚动，不应拉高左侧阵型区域
- 仪式战为单场战斗，不进入自动连战

### 4.3 连战逻辑

- 胜利且有存活单位时会自动进入下一场
- 下一场继承存活英雄的 HP / MP
- 失败或无法继续时打开复盘弹窗
- 复盘展示的是本次连战会话累计数据，不是最后一场
- 连战会话只应在重新侦察或切换节点时重置

### 4.4 战斗结束后的回写

- 胜利且有掉落：`EquipmentInventoryProvider.collectBattleDrops(runtime.drops)`
- 胜利：`EquipmentInventoryProvider.grantBattleHeroExp(参战英雄, 敌方等级列表)`
- 无论胜负都会统计材料获得数和敌方击杀数
- 最后调用 `MapSystemProvider.reportMissionBattleOutcome(...)` 回写地区任务进度
- 仪式战胜利后，额外回写仪式完成态、奖励、传说装备解锁与地区压制 100

## 5. battleAdapters 做什么

`src/lib/battleAdapters.ts` 负责把前台的英雄数据转成战斗可用模板。

### 5.1 我方模板

输入：

- `heroes`（来自 `HeroRosterProvider`）
- `formation`
- `heroLoadouts`
- `equippedByHero`
- `itemMap`

输出：`BattleUnitTemplate[]`

这里会把英雄等级、成长、装备和职业倾向合成战斗模板。
若英雄穿戴传说装备，还会把对应被动技能 id 追加到 `tags`，供 `battleEngine` 在运行时触发真实效果。

### 5.2 敌方模板

- 入口：`buildEnemyTeamTemplates`
- 实际来源：`src/data/battleUnits.ts`
-- 会根据 node archetype、地图压制和 `sourceNodeId` 生成敌人数量与等级
-- 若节点存在固定战斗配置，优先使用节点敌人池；否则回退到全局敌人池
-- 无序节点的 BL3 / BL2 / BL1 已接入分层分布参数
-- 当前敌人带 5 级稀有度，稀有度越高权重越低、难度越高、掉落倾向越高
-- 当前敌人种族：亡灵 / 野兽 / 人类 / 异兽（`aberrant`）
- 仪式 Boss 阵容走 `buildFixedEnemyTeamTemplates`，不混入普通随机池

## 6. battleEngine 负责什么

`src/lib/battleEngine.ts` 负责战斗核心：行动条、技能、目标、伤害/治疗/护盾、状态、元素、日志、掉落、回放。

当前还额外承担“传说装备被动运行时结算”：

1. 战斗开始护盾
2. 暗属性承伤修正
3. 受伤/治疗触发的层数被动
4. 技能后回蓝与低血追击

这些效果的数据入口仍在传说装备配置，但真正的触发时机在 `battleEngine.ts`，不要只改背包文案。

## 7. 技能系统当前结构

- 通用 / 职业 / 敌方 / 传奇补充技能都从 `src/data/battleSkills/*/*.json` 和 `src/data/config/legendaryHeroSkills.json` 读取
- `src/data/battleSkills.ts` 负责装载与解析
- HeroPage 候选和 BattleEngine 运行共用同一份技能定义
- 本次新增 `enemy-boss` 技能目录，用于仪式 Boss 的专属技能、被动与天赋

## 8. 掉落系统当前结构

- 掉落由 `battleEngine.ts` 的 `generateDrops` 生成
- 材料目录来自 `src/data/battleDrops.ts`
- 材料按种族池掉落，压制值越高，高品质掉落权重越高
- 战斗结束后 `collectBattleDrops` 会把材料和装备写入全局背包

## 9. 常见改动定位

| 需求 | 文件 |
| --- | --- |
| 改战斗速度 / 行动条 / 结算时机 | `src/lib/battleEngine.ts` `src/pages/BattlePage.tsx` |
| 改我方属性如何从装备映射 | `src/lib/battleAdapters.ts` |
| 改敌人数量 / 等级 / 原型 | `src/data/battleUnits.ts` |
| 改技能字段或 JSON 解析 | `src/data/battleSkills.ts` |
| 改技能内容 | `src/data/battleSkills/*/*.json` |
| 改元素联动 | `src/data/battleElementTriggers.ts` `src/lib/battleEngine.ts` |
| 改掉落表 | `src/data/battleDrops.ts` |
| 改复盘 UI | `src/pages/BattlePage.tsx` |

## 10. 当前注意事项

1. 战斗页连战会自动开始下一场。
2. 战斗结果会真实回写任务进度和材料库存。
3. 英雄页展示属性不是战斗最终属性。
4. 技能 JSON 改错时，问题可能同时表现为 HeroPage 候选异常和 BattlePage 运行异常。
