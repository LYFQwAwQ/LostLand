# 2026-03-18-建筑材料交易与组织建筑升级接入

## 1. 任务信息

- 日期：2026-03-18
- 开发者：Codex
- 任务名称：建筑材料交易与组织建筑升级接入
- 需求来源：用户提出“建筑材料交易 + 建筑升级系统”设定接入。

## 2. 改动目标

- 本次要解决什么问题：
  - 在 ST1 节点新增“建筑材料交易”页面，按“基础价 + 主城浮动百分比”定价并真实扣金入包。
  - 建筑材料与战斗材料合并到同一背包，并新增“仅建筑材料”筛选按钮。
  - 组织建筑升级改为“金币 + 建筑材料”真实消耗，统一开放到 Lv.6。
  - 接通基地核心评级上限、任务大厅任务上限、铁匠铺强化成功率加成三条等级效果链路。
  - 新增训练营建筑与槽位展示（可点击占位，暂不接入真实训练流程）。
- 不在本次范围内的内容：
  - 建筑材料卖出、仓储上限、跨主城套利提示等交易增强能力。
  - 训练营真实挂机经验结算与任务大厅高级任务概率系统。
  - 建筑 Lv.6 以上扩展（Lv.7~10）。
