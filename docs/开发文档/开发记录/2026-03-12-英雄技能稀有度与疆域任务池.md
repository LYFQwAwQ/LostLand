# 2026-03-12-英雄技能稀有度与疆域任务池

## 1. 任务信息

- 日期：2026-03-12
- 开发者：Codex
- 任务名称：英雄技能稀有度接入与布告栏任务疆域化
- 需求来源：用户需求（随机英雄技能稀有度概率 + 布告栏任务按疆域生成）

## 2. 改动目标

- 本次要解决什么问题：
  - 给英雄已学技能增加稀有度属性，并让普通随机英雄主动/被动技能按概率生成稀有度。
  - 将传奇专属技能/天赋稀有度统一为传说，并通过配置文件读取。
  - 布告栏任务的可用怪物/材料池从“当前地区”扩展为“当前疆域全部地区”。
  - 讨伐任务进度回写从“仅当前地区任务”改为“同疆域任务同步推进”。
- 不在本次范围内的内容：
  - 未改动任务刷新周期与轮换策略。
  - 未接入赏金/声望到正式经济系统。

- 每个文件改了什么（1-2 句）：
  - `src/types/game.ts`：新增 `HeroSkillRarity`，并在 `Hero.learnedSkills` 增加 `rarityBySkillId`。
  - `src/data/heroRoster.ts`：新增随机技能稀有度权重读取与赋值逻辑；传奇专属技能/天赋稀有度改为从 `legendaryHeroSkills.json` 读取并覆盖到英雄已学技能稀有度映射。
  - `src/data/config/heroGeneration.json`：新增 `randomSkillRarityWeights`（默认 `0.8/0.19/0.01`）。
  - `src/data/battleSkills/*/*.json`：玩家可用主动/被动技能补充 `rarity` 字段，作为技能基础稀有度来源。
  - `src/data/battleSkills.ts` / `src/types/battle.ts`：主动/被动技能定义与解析新增 `rarity` 字段支持。
  - `src/data/config/legendaryHeroSkills.json`：传奇专属天赋/主动/被动全部标注 `rarity: "legendary"`。
  - `src/pages/HeroPage.tsx`：技能悬浮详情新增已学技能稀有度展示。
  - `src/lib/bulletinMissionSystem.ts`：任务可完成性扫描改为按疆域聚合地区资源；任务描述文案改为疆域范围。
  - `src/state/MapSystemProvider.tsx`：任务生成传入地区解析器；战斗回写改为同疆域任务同步更新。
  - `src/pages/NodeActionPage.tsx`：任务目标文案与空列表提示改为疆域语义。

## 4. 影响范围

- 影响页面/模块：
  - 英雄页技能配置悬浮详情。
  - 随机英雄生成链路。
  - 节点功能页布告栏任务展示与任务进度回写链路。
- 是否影响数值平衡：
  - 是。普通随机英雄技能稀有度分布由配置控制，默认 80%/19%/1%。
- 是否影响旧功能：
  - 兼容旧英雄数据：若缺失 `rarityBySkillId`，会按默认规则补全并保留可用性。
