# 2026-03-08-记忆系统改为手动穿戴默认空槽

## 1. 任务信息

- 日期：2026-03-08
- 开发者：Codex
- 任务名称：记忆默认值逻辑修正
- 需求来源：用户反馈

## 2. 改动目标

- 本次要解决什么问题：
  - 新英雄不应自带记忆，记忆应像装备一样需要手动穿戴才生效。
- 不在本次范围内的内容：
  - 记忆获取流程
  - 记忆数值与战斗结算联动扩展

## 3. 代码改动清单

- 改动文件：
  - `src/state/BattleSetupProvider.tsx`
  - `src/pages/HeroPage.tsx`
  - `src/data/heroMemories.ts`
- 每个文件改了什么（1-2 句）：
  - `BattleSetupProvider`：记忆默认值改为 `null`，快照导入增加职业合法性校验，导出保持空槽为 `null`。
  - `HeroPage`：记忆 UI 增加“未穿戴”选项，未穿戴时展示空槽文案，不再自动回填默认记忆。
  - `heroMemories`：移除“职业默认记忆”常量，避免与手动穿戴模型冲突。

## 4. 影响范围

- 影响页面/模块：
  - 英雄页记忆标签
  - 战斗配置状态中的 `heroMemories`
- 是否影响数值平衡：
  - 否（仅修正默认状态语义）
- 是否影响旧功能：
  - 会影响“新英雄默认显示记忆”的旧行为；现在为默认空槽。

## 5. 验证记录

- 手动验证路径：
  - 启动项目后打开任意新生成英雄 -> 记忆标签
  - 检查默认显示“未穿戴记忆”
  - 下拉选择任意记忆后可正常写入，再切换“未穿戴”可清空
- 验证结果：
  - 逻辑符合预期。
- 未覆盖风险：
  - 暂未接入记忆实际战斗效果计算，本次仅处理状态与 UI 语义。
