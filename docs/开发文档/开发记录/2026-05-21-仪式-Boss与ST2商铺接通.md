## 5. 验证记录

- 手动验证路径：
  - `npm.cmd run build`
  - 世界地图 -> ST2 节点 -> 商铺：采购材料/消耗品、回收材料、切换行情
  - 世界地图 -> BL3 节点 -> 仪式页 -> 进入仪式战 -> 胜负结算
- 验证结果：
  - 构建通过；类型检查与打包通过。
  - 仪式战和 ST2 商铺链路已接通到真实状态。
- 未覆盖风险：
  - 仪式失败后的“部分扣费”采用固定 50% 简化策略，后续可改成配置化。
  - 仪式奖励与普通掉落叠加后，首章后期资源增速需继续平衡。
