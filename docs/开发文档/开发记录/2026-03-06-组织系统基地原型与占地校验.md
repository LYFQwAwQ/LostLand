# 组织系统基地原型与占地校验

## 1. 任务信息

- 日期：2026-03-06
- 开发者：Codex
- 任务名称：组织系统基础界面与建造交互原型
- 需求来源：用户需求（组织入口、40x40 网格、缩放平移、占地校验、评级占位）

## 2. 改动目标

- 本次要解决什么问题：
  - 新增组织基地主界面并接入左侧导航入口。
  - 实现通用建筑放置框架（占地形状、唯一建筑、冲突与越界校验）。
  - 提供 40x40 网格下的缩放与平移能力，支持后续参数化调整。
  - 功能建筑点击后进入占位弹窗，预留后续子系统接入点。
- 不在本次范围内的内容：
  - 功能建筑真实业务界面（铁匠铺/远征/图书馆）与后端数据接入。
  - 组织评级正式升级条件与跨系统数值联动。

## 3. 代码改动清单

- 改动文件：
  - `src/types/organization.ts`
  - `src/data/organizationData.ts`
  - `src/state/OrganizationProvider.tsx`
  - `src/pages/OrganizationPage.tsx`
  - `src/main.tsx`
  - `src/App.tsx`
  - `src/components/layout/MainLayout.tsx`
  - `src/styles.css`
- 每个文件改了什么（1-2 句）：
  - `organization.ts`：补齐组织建筑、占地校验、评级状态等类型定义。
  - `organizationData.ts`：新增组织系统可调参数与初版建筑定义（含形状与唯一性）。
  - `OrganizationProvider.tsx`：实现组织状态容器与建造/拆除/升级/经验占位接口。
  - `OrganizationPage.tsx`：实现组织页原型（建筑面板、40x40 地图、占地预览、缩放平移、占位弹窗）。
  - `main.tsx`：接入 `OrganizationProvider` 到全局 Provider 链。
  - `App.tsx`：新增 `/organization` 路由。
  - `MainLayout.tsx`：左侧导航新增“组织基地”入口。
  - `styles.css`：新增 `organization-*` 样式和响应式布局。
