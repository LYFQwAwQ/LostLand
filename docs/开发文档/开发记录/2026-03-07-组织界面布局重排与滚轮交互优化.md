# 组织界面布局重排与滚轮交互优化

## 1. 任务信息

- 日期：2026-03-07
- 开发者：Codex
- 任务名称：组织页 UI 重排与滚轮交互优化
- 需求来源：用户需求（减少侧栏堆叠、避免滚轮冲突、常用按钮免滚动可见）

## 2. 改动目标

- 本次要解决什么问题：
  - 组织页信息块过度堆叠在左侧，导致常用功能需滚动才能看到。
  - 地图缩放时外层面板也在滚动，交互冲突明显。
- 不在本次范围内的内容：
  - 组织功能建筑子界面业务实现（仍为占位）。
  - 组织评级升级规则正式接入（仍是模拟接口）。

## 3. 代码改动清单

- 改动文件：
  - `src/pages/OrganizationPage.tsx`
  - `src/styles.css`
- 每个文件改了什么（1-2 句）：
  - `OrganizationPage.tsx`：将组织评级移动到标题区横向展示；左侧仅保留“选中建筑”；将“建筑面板+编辑控制”整体移到右侧；滚轮缩放事件增加 `stopPropagation`。
  - `styles.css`：组织页改为三栏布局并新增顶部评级样式；调整响应式断点；通过 `overscroll-behavior` 限制滚轮事件外溢，降低“缩放+滚动”冲突。

## 4. 影响范围

- 影响页面/模块：
  - `组织基地` 页面布局与交互。
- 是否影响数值平衡：
  - 否。
- 是否影响旧功能：
  - 否，组织系统逻辑（建造、占地校验、缩放平移）保持不变。

## 5. 验证记录

- 手动验证路径：
  - 进入 `组织基地` 页面，确认顶部评级显示、左中右分区位置。
  - 使用滚轮在地图区域缩放，观察外层是否同步滚动。
  - 验证右侧建筑面板和编辑控制可直接看到并可操作。
- 验证结果：
  - `npm run build` 通过（TypeScript + Vite）。
  - 布局重排生效，地图缩放时不再同时触发外层滚动。
- 未覆盖风险：
  - 极小分辨率下仍可能出现整体页面滚动，当前通过响应式降级处理。
