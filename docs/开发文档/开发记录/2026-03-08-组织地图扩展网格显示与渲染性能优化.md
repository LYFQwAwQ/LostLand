# 组织地图扩展网格显示与渲染性能优化

## 1. 任务信息

- 日期：2026-03-08
- 开发者：Codex
- 任务名称：组织地图扩展模式网格显示 + 卡顿优化
- 需求来源：用户反馈（扩展模式缺少可放置网格提示，地图交互卡顿）

## 2. 改动目标

- 本次要解决什么问题：
  - 扩展模式下需要明确显示可放置格子，避免玩家不知道可扩展位置。
  - 组织地图在大画布下格子渲染过多，导致交互卡顿。
  - 平移模式中鼠标位于普通格子区域时也应可拖动，只有建筑本体可拦截。
- 不在本次范围内的内容：
  - 组织扩展数值规则（扩展大小、相邻/不相交判定）调整。

## 3. 代码改动清单

- 改动文件：
  - `src/pages/OrganizationPage.tsx`
  - `src/styles.css`
- 每个文件改了什么（1-2 句）：
  - `OrganizationPage.tsx`：新增视口尺寸监听和可见区域裁剪渲染，只渲染当前视口内格子；扩展模式下显示外圈格子，建造模式下隐藏外圈格子；平移模式下地块层透传事件。
  - `styles.css`：组织地图网格容器改为绝对定位绘制；新增 `organization-grid.pan-pass-through` 透传规则，确保非建筑区域可拖拽平移。

## 4. 影响范围

- 影响页面/模块：
  - `组织基地` 页面地图交互与渲染性能。
- 是否影响数值平衡：
  - 否。
- 是否影响旧功能：
  - 否，建造/扩展/平移逻辑保持原有规则，仅优化显示与交互细节。

## 5. 验证记录

- 手动验证路径：
  - 进入组织基地，切到扩展模式，确认外圈出现格子并可辅助判断扩展位置。
  - 在平移模式下分别在空白格子区与建筑标签上按下鼠标，确认“空白可拖、建筑可拦截”。
  - 大幅缩放和平移地图，观察拖拽与悬停反馈是否顺滑。
- 验证结果：
  - `npm run build` 通过（TypeScript + Vite 打包成功）。
- 未覆盖风险：
  - 在极低性能设备上，扩展模式下可见格子数量仍可能带来轻微抖动，后续可进一步引入事件节流。
