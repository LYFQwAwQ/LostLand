# 2026-04-29-英雄立绘占位符收敛与弥亚保留

## 1. 任务信息

- 日期：2026-04-29
- 开发者：Codex
- 任务名称：英雄立绘占位符收敛与弥亚保留
- 需求来源：用户反馈（现有英雄立绘存在大量不合适图片，要求统一替换为占位符，仅保留弥亚立绘）

## 2. 改动目标

- 本次要解决什么问题：
  - 清理当前英雄系统中非弥亚角色使用的杂项图片来源。
  - 将非弥亚英雄立绘统一收敛到本地占位符，避免继续依赖外链图片。
  - 保留弥亚立绘 `public/images/heroes/Miya.png` 作为唯一非占位符英雄图。
- 不在本次范围内的内容：
  - 不调整英雄生成逻辑（随机数量、职业权重、传奇概率等）。
  - 不改动英雄技能、属性、战斗与队伍相关逻辑。
  - 不移除“弥亚固定初始注入”测试逻辑。

## 3. 代码改动清单

- 改动文件：
  - `public/images/heroes/hero-placeholder.svg`
  - `src/data/config/heroGeneration.json`
  - `src/data/config/legendaryHeroes.json`
  - `src/data/heroRoster.ts`
- 每个文件改了什么（1-2 句）：
  - `public/images/heroes/hero-placeholder.svg`
    - 新增本地英雄立绘占位符资源，供非弥亚角色统一使用。
  - `src/data/config/heroGeneration.json`
    - 将四职业 `imagePoolByClass` 全部替换为占位符路径 `/images/heroes/hero-placeholder.svg`。
  - `src/data/config/legendaryHeroes.json`
    - 将非弥亚传奇英雄（奥里克、莉拉、赛拉）的 `image` 改为占位符；弥亚保持 `Miya.png`。
  - `src/data/heroRoster.ts`
    - 将固定初始英雄阿瑟、塞琳娜的硬编码图片改为占位符，确保启动后非弥亚默认英雄也走统一占位图。

## 4. 影响范围

- 影响页面/模块：
  - `HeroPage` 英雄属性与记忆页立绘展示
  - `TeamPage` 编队列表与槽位中的头像展示
  - `BattlePage`（通过 `battleAdapters`）角色头像透传展示
  - 所有依赖 `Hero.image` 的界面
- 是否影响数值平衡：
  - 否（仅资源与配置层面的图片路径变更）。
- 是否影响旧功能：
  - 功能流程不变，展示图来源变更为“弥亚保留原图，其他统一占位图”。
