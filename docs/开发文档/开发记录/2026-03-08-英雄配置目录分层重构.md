# 2026-03-08-英雄配置目录分层重构

## 1. 任务信息

- 日期：2026-03-08
- 开发者：Codex
- 任务名称：英雄系统配置化与游侠职业接入
- 需求来源：用户提出“按百科设计实现英雄系统”，并要求先完成可配置版本

## 2. 改动目标

- 本次要解决什么问题：
  - 英雄来源从固定样本升级为“固定英雄 + 启动随机英雄”，并支持小概率传奇。
  - 英雄与技能规则新增游侠职业。
  - 英雄系统核心参数改为 JSON 可配置，便于后续策划调参。
  - 新增游侠专属装备栏样式（2手部+1护甲+1战靴+4饰品）。
- 不在本次范围内的内容：
  - 酒馆招募流程闭环（展示、签约、扣资源、入队）
  - 传奇英雄获取条件（BOSS 材料/任务解锁）
  - 英雄数据本地持久化

  - 战斗引擎 `scaling` 增加 `agi` 系数支持，保障游侠技能数值生效。
  - 新增游侠职业记忆候选、游侠装备槽位定义、战靴子类型模板。
  - 英雄页接入游侠专属装备栏组件与职业分支显示。
  - 新增 `ranger` 目录技能配置；补充 paladin/mage 传奇天赋；`basic_attack` 开放给 ranger。

## 4. 影响范围

- 影响页面/模块：
  - 英雄页、队伍页、战斗页、背包页（职业/装备槽位/战斗构筑联动）
  - 英雄数据初始化链路（`mockData -> heroRoster`）
  - 战斗技能配置目录与解析链路
- 是否影响数值平衡：
  - 是。新增游侠职业、传奇天赋、传奇英雄固定属性，且随机英雄生成会改变每次启动开局强度分布。
- 是否影响旧功能：
  - 保留原有阿瑟/塞琳娜固定英雄；原英雄页、装备页、战斗页主流程继续可用。

## 5. 验证记录

- 手动验证路径：
  - `npm run build`
  - 打开英雄页检查 4 名英雄（固定 2 + 随机 2）
  - 切换到随机游侠英雄，检查装备栏是否为 8 槽布局并可打开装备选择弹窗
  - 进入队伍页/战斗页，确认随机英雄可上阵并能正常读取技能配置
- 验证结果：
  - 构建通过；类型检查通过；游侠装备栏与技能配置链路可编译并接入。
- 未覆盖风险：
  - 未实现酒馆招募与传奇获取流程，因此配置中的传奇仅通过“启动随机位概率”出现。
  - 未做随机生成稳定性统计（长期分布、极值波动）。
