# 2026-03-03-装备系统基础生成与调试面板

## 1. 任务信息

- 日期：2026-03-03
- 开发者：Codex
- 任务名称：装备系统基础生成与调试面板
- 需求来源：用户需求（基于《百科》《装备设计》落地第一版）

## 2. 改动目标

- 本次要解决什么问题：
  - 落地独立可调用的装备生成系统（数据结构 + 生成逻辑）。
  - 提供可复现的批量抽样能力（Seed）。
  - 提供临时调试界面方便查看 Rank/Quality/词条效果。
  - 增加单元测试覆盖核心规则。
- 不在本次范围内的内容：
  - 不接入节点掉落、背包、穿戴限制与锻造产线。
  - 不落地职业可穿戴映射规则（留待下一版本）。

## 3. 代码改动清单

- 改动文件：
  - `src/types/game.ts`
  - `src/lib/equipmentSystem.ts`
  - `src/data/equipmentTemplates.ts`
  - `src/components/hero/EquipmentSandboxPanel.tsx`
  - `src/pages/HeroPage.tsx`
  - `src/styles.css`
  - `tests/equipmentSystem.test.ts`
- 每个文件改了什么（1-2 句）：
  - `src/types/game.ts`：新增装备系统核心类型（模板、环境修正、生成请求、生成结果）。
  - `src/lib/equipmentSystem.ts`：实现模板池抽取、Rank/Quality 随机、词条生成（不去重）、插槽计算、批量生成接口。
  - `src/data/equipmentTemplates.ts`：新增首批调试模板与词条池配置。
  - `src/components/hero/EquipmentSandboxPanel.tsx`：新增临时调试面板，可设置 Seed/等级/样本数并查看分布与明细。
  - `src/pages/HeroPage.tsx`：在“装备体系”页接入调试面板。
  - `src/styles.css`：补充调试面板样式与响应式布局。
  - `tests/equipmentSystem.test.ts`：新增 7 条单元测试，覆盖核心规则。
