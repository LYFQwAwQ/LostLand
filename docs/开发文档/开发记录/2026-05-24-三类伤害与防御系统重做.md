# 2026-05-24-三类伤害与防御系统重做

## 1. 任务信息

- 日期：2026-05-24
- 开发者：Codex
- 任务名称：三类伤害与防御系统重做
- 需求来源：用户提出希望将伤害分为物理、魔法、元素，并重做防御系统以增加游戏深度

## 2. 改动目标

- 本次要解决什么问题：
  - 将战斗伤害从旧的统一防御口径扩展为物理、魔法、元素三类伤害。
  - 让防御系统分别对应物防、魔防、元素抗性，并保留最终增伤/最终减伤作为通用末端乘区。
  - 让英雄属性页、装备词条与战斗公式的属性口径保持一致。
- 不在本次范围内的内容：
  - 不重做职业技能树与职业定位。
  - 不大规模重配全部敌人、技能和装备数值。
  - 不新增独立数值配置文件，只在现有类型、公式、模板与文档中落地。

## 3. 代码改动清单

- 改动文件：
  - `src/types/battle.ts`
  - `src/types/game.ts`
  - `src/lib/battleEngine.ts`
  - `src/lib/battleAdapters.ts`
  - `src/data/battleSkills.ts`
  - `src/data/battleUnits.ts`
  - `src/data/equipmentTemplates.ts`
  - `src/data/legendaryEquipments.ts`
  - `src/pages/HeroPage.tsx`
  - `src/pages/InventoryPage.tsx`
  - `docs/开发文档/04-英雄与队伍模块.md`
  - `docs/开发文档/07-战斗系统模块.md`
  - `docs/开发文档/配置文件修改指南.md`
  - `docs/开发文档/战斗技能配置文件说明-策划.md`
- 每个文件改了什么（1-2 句）：
  - `battle.ts`：扩展 `BattleDamageType` 为 `physical | magic | elemental`，新增物防/魔防、物穿/法穿、三类类型增伤字段。
  - `game.ts`：扩展装备词条 key，允许魔防、魔穿、三类增伤、最终增伤/减伤等装备字段。
  - `battleEngine.ts`：重写伤害公式分支，物理走物防，魔法走魔防，元素走元素抗性；最终增伤/减伤仍对三类伤害生效。
  - `battleAdapters.ts`：将英雄 `def` 映射为物防，按职业派生魔防与基础专精，装备新旧词条统一映射到新战斗字段。
  - `battleSkills.ts`：支持 `elemental` 伤害类型，并兼容旧 modifier 字段到新字段。
  - `battleUnits.ts`：敌人模板输出新增物防、魔防、物穿、魔穿、类型增伤字段。
  - `equipmentTemplates.ts`：装备词条池新增魔防、魔穿、物理增伤、魔法增伤等条目，并将全元素加成文案收敛为元素伤害增加。
  - `legendaryEquipments.ts` / `InventoryPage.tsx`：补齐新装备词条白名单与展示文案。
  - `HeroPage.tsx`：属性页战斗数值展示改为三伤害与三防御口径。

## 4. 影响范围

- 影响页面/模块：
  - 英雄属性页战斗数值展示
  - 背包装备/传说装备词条展示
  - 战斗伤害结算
  - 技能 JSON 解析
  - 敌人模板生成
  - 装备随机词条生成
- 是否影响数值平衡：
  - 是。伤害公式从统一 `DEF` 防御改成物理/魔法/元素分流，装备百分比词条也修正为按 `0.01 = 1%` 生效，整体战斗体感会变化。
- 是否影响旧功能：
  - 有兼容处理。旧英雄 `def`、装备 `penetration` / `armorPiercePct` / `allBoost`、技能 modifier `def` / `penetration` / `armorPenPct` / `allBoost` 仍可读取并映射到新口径。
