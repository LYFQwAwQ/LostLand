# 2026-03-07-拖拽编队状态扩展与技能配置化

## 1. 任务信息

- 日期：2026-03-07
- 开发者：Codex
- 任务名称：拖拽编队与多预设 + 战斗状态机制扩展 + 技能库配置文件化
- 需求来源：用户需求（完成项目 TODO 项并提升策划可配置能力）

## 2. 改动目标

- 本次要解决什么问题：
  - 队伍页补齐拖拽编队与 10 套预设保存/加载。
  - 预设从“仅编队”升级为全量构筑快照（编队、技能槽位、装备、记忆占位）。
  - 战斗状态扩展到护盾、净化、驱散、免疫、嘲讽强制目标。
  - 技能库改为 JSON 配置驱动，支持策划不改代码新增/删除/修改技能。
- 不在本次范围内的内容：
  - 不接入地图压制对掉落稀有度/保底/数量修正。
  - 不实现脚本表达式引擎（仍使用类型化配置 + 引擎执行）。

## 3. 代码改动清单

- 改动文件：
  - `src/pages/TeamPage.tsx`
  - `src/styles.css`
  - `src/state/BattleSetupProvider.tsx`
  - `src/state/EquipmentInventoryProvider.tsx`
  - `src/pages/HeroPage.tsx`
  - `src/data/heroMemories.ts`
  - `src/types/battle.ts`
  - `src/lib/battleEngine.ts`
  - `src/pages/BattlePage.tsx`
  - `src/data/battleSkills.config.json`
  - `src/data/battleSkills.ts`
  - `src/data/battleUnits.ts`
- 每个文件改了什么（1-2 句）：
  - 队伍页改为“点击 + 拖拽”并存，新增 10 套预设管理面板（命名/保存/载入/清空）。
  - `BattleSetupProvider` 新增记忆占位状态与战斗构筑快照导入导出。
  - `EquipmentInventoryProvider` 新增装备快照导入导出（`seed + equippedByHero`）。
  - 英雄记忆页改为可选占位记忆，供预设保存恢复。
  - 战斗类型与引擎新增 `shielded/immune/taunted` 及 `extraEffects` 执行链（shield/cleanse/dispel/actionDelta/applyStatus）。
  - 战斗目标选择接入嘲讽强制目标，状态显示与复盘文案同步中文化。
  - 技能定义迁移为 `battleSkills.config.json`，`battleSkills.ts` 改为加载与校验层。
  - 默认职业技能模板补入新机制技能（挑衅、护盾免疫、净化、驱散）。
