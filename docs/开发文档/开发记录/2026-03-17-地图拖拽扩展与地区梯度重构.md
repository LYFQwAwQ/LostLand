# 2026-03-17-地图拖拽扩展与地区梯度重构

## 1. 任务信息

- 日期：2026-03-17
- 开发者：Codex
- 任务名称：地图拖拽扩展与地区梯度重构
- 需求来源：用户提出“地图点位分散、可拖动并快速回中；新增两个地区，并满足离流明城越远越无序、越危险”。

## 2. 改动目标

- 本次要解决什么问题：
  - 地图节点显示过于集中，阅读压力高。
  - 超出可视范围后无法平移查看。
  - 人族疆域地区数量不足，且未体现与流明城距离相关的稳定/无序和难度梯度。
- 不在本次范围内的内容：
  - 月度结算算法本体（`monthlySimulation.ts`）未重构。
  - 随机地图系统仍保留，不删除。

## 3. 代码改动清单

- 改动文件：
  - `src/pages/WorldMapPage.tsx`
  - `src/styles.css`
  - `src/config/world/worldHierarchy.json`
  - `src/data/fixedRegionTopologies.ts`
- 每个文件改了什么（1-2 句）：
  - `WorldMapPage.tsx`：新增地图拖拽平移、快速回中、放大画布渲染；节点标题与距离面板统一显示“地名 + 实体类型”。
  - `styles.css`：新增 `map-pan-canvas`、`map-center-btn` 与拖拽态样式，补齐抓手光标与移动过渡。
  - `worldHierarchy.json`：人族疆域新增 `silvergrain-meadows`、`blightfang-outerreach`，并重排六地区邻接与选区坐标。
  - `fixedRegionTopologies.ts`：重配现有四区稳定/无序比例与难度上限，新增两区完整固定节点/边/敌人池配置，形成距离梯度。

## 4. 影响范围

- 影响页面/模块：
  - 世界地图页面（交互与显示）
  - 固定地图地区生成
  - 人族疆域地区选择弹窗与邻接切换
- 是否影响数值平衡：
  - 是。涉及各区 `mapSuppression`、稳定/无序比例、BL 层级分布与节点敌人池权重。
- 是否影响旧功能：
  - 旧随机地图系统代码仍保留，仅固定地图接入策略不变。
