# 开发记录

## 1. 任务信息

- 日期：2026-03-09
- 开发者：Codex
- 任务名称：世界地图多层结构与懒生成改造
- 需求来源：用户提出“大陆->疆域->地区”多层地图与弹窗选择流程

## 2. 改动目标

- 本次要解决什么问题：
  - 将原有“5 大陆=5 地区”的单层模型升级为“大陆->疆域->地区->节点”多层结构。
  - 地区改为按需生成（懒生成），避免开局一次性构建全部地区。
  - 地图入口改为三参数（`continent/dominion/region`），并实现大陆点击后“疆域弹窗 -> 地区弹窗”两级选择。
  - 在地区地图界面新增“邻接地区快捷切换”按钮。
- 不在本次范围内的内容：
  - 大陆顶级掉落池的实际掉落计算接入（仅保留配置字段，已写入 TODO）。
  - 全世界批量月结算（当前仍为“仅结算当前地区”，已写入 TODO）。
