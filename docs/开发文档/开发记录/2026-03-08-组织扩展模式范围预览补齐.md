# 组织扩展模式范围预览补齐

## 1. 任务信息

- 日期：2026-03-08
- 开发者：Codex
- 任务名称：组织扩展模式范围预览补齐
- 需求来源：用户反馈（扩展模式看不到将要扩展的具体范围）

## 2. 改动目标

- 本次要解决什么问题：
  - 扩展模式缺少像建造模式一样的整块范围预览，玩家无法预判点击后扩展区域。
- 不在本次范围内的内容：
  - 扩展块大小、扩展次数来源与组织等级规则调整。

## 3. 代码改动清单

- 改动文件：
  - `src/types/organization.ts`
  - `src/state/OrganizationProvider.tsx`
  - `src/pages/OrganizationPage.tsx`
- 每个文件改了什么（1-2 句）：
  - `organization.ts`：新增 `OrganizationTerritoryExpandCheckResult`，用于扩展范围预检返回。
  - `OrganizationProvider.tsx`：新增 `checkTerritoryExpansion()`，统一扩展边界/相邻/不相交校验；`expandTerritory()` 复用该校验结果。
  - `OrganizationPage.tsx`：扩展模式下根据鼠标悬停计算并显示整块范围预览（可扩展/不可扩展颜色），同时在右侧显示不可扩展原因。

## 4. 影响范围

- 影响页面/模块：
  - `组织基地` 页面扩展模式可视反馈。
  - `OrganizationProvider` 对外接口（新增扩展预检方法）。
- 是否影响数值平衡：
  - 否。
- 是否影响旧功能：
  - 否，扩展实际规则保持一致，仅补齐预览和提示。

## 5. 验证记录

- 手动验证路径：
  - 进入组织基地，切到扩展模式，移动鼠标观察是否出现 `7x7` 范围预览。
  - 在非法位置悬停（越界/不相邻/相交），确认预览为不可扩展色并提示原因。
  - 在合法位置点击扩展，确认实际扩展范围与预览一致。
- 验证结果：
  - `npm run build` 通过（TypeScript + Vite 打包成功）。
- 未覆盖风险：
  - 高频率移动鼠标时会持续触发预检计算，后续如需更极致性能可加轻量节流。
