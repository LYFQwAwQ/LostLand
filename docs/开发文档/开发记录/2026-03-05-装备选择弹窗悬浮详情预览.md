# 2026-03-05-装备选择弹窗悬浮详情预览

## 1. 任务信息

- 日期：2026-03-05
- 开发者：Codex
- 任务名称：装备选择弹窗悬浮详情预览
- 需求来源：用户反馈（装备选择弹窗中无法看到装备详细属性）

## 2. 改动目标

- 本次要解决什么问题：
  - 在英雄装备“选择装备弹窗”中，鼠标悬停装备项时展示半透明详细属性浮层。
  - 浮层信息参考背包详情：基础属性、附加词条、品质、品阶、插槽、Rank 增幅等。
- 不在本次范围内的内容：
  - 不改动背包页详情弹窗布局。
  - 不改动装备生成、筛选、穿戴规则。

## 3. 代码改动清单

- 改动文件：
  - `src/pages/HeroPage.tsx`
  - `src/styles.css`
- 每个文件改了什么（1-2 句）：
  - `HeroPage.tsx`：在装备选择列表项上新增 `mouseenter/mousemove/mouseleave` 事件，渲染跟随鼠标位置的装备详情浮层。
  - `styles.css`：新增悬浮详情浮层样式（半透明、模糊背景、分区属性列表），并在小屏下隐藏该浮层。

## 4. 影响范围

- 影响页面/模块：
  - 英雄页 `装备体系` -> 装备选择弹窗。
- 是否影响数值平衡：
  - 否（仅展示层增强）。
- 是否影响旧功能：
  - 不影响双手武器占位、跨英雄唯一穿戴等既有逻辑。

## 5. 验证记录

- 手动验证路径：
  - 进入 `英雄殿堂 -> 装备体系`，点击任一槽位打开装备选择弹窗。
  - 鼠标悬停在装备项上，确认出现半透明详情浮层并包含 T1/T2 详细属性。
  - 移出装备项或关闭弹窗，浮层消失。
- 验证结果：
  - 构建通过：`npm run build`
  - 单测通过：`node --experimental-strip-types --test --test-isolation=none tests/equipmentSystem.test.ts`（7/7）
- 未覆盖风险：
  - 移动端无 hover 行为，当前策略为隐藏该浮层。
