# 2026-03-18-英雄等级经验与属性成长系统

## 1. 任务信息

- 日期：2026-03-18
- 开发者：Codex
- 任务名称：英雄等级、经验与基础属性成长系统接入
- 需求来源：用户需求（英雄初始 Lv.1、上限 Lv.100；经验随敌人等级与数量变化；敌我等级差影响经验；每场胜利给所有参战英雄发经验）

## 2. 改动目标

- 本次要解决什么问题：
  - 接通英雄等级与经验状态，支持战斗胜利后经验结算与升级。
  - 让英雄基础属性按等级成长，且成长值可在属性页展示。
  - 区分随机英雄成长（职业基础 + 波动）与传奇英雄成长（固定且独特）。
- 不在本次范围内的内容：
  - 训练营建筑经验加成接入。
  - 挂机系统、酒馆招募状态源重构、后端持久化。

## 3. 代码改动清单

- 改动文件：
  - `src/types/game.ts`
  - `src/data/config/heroGeneration.json`
  - `src/data/config/legendaryHeroes.json`
  - `src/data/config/heroProgressionConfig.ts`
  - `src/data/heroRoster.ts`
  - `src/state/EquipmentInventoryProvider.tsx`
  - `src/lib/battleAdapters.ts`
  - `src/pages/BattlePage.tsx`
  - `src/pages/HeroPage.tsx`
  - `src/styles.css`
- 每个文件改了什么（1-2 句）：
  - `game.ts`：新增英雄成长与进度类型，`Hero` 新增 `statGrowth` 字段。
  - `heroGeneration.json`：新增 `growthProfileByClass`，定义随机英雄职业成长基准与波动。
  - `legendaryHeroes.json`：为每个传奇英雄新增固定 `growth` 配置。
  - `heroProgressionConfig.ts`：新增等级/经验配置与计算函数（等级上限、经验曲线、战斗经验与等级差修正）。
  - `heroRoster.ts`：随机英雄生成成长值，传奇读取固定成长，固定初始英雄补齐成长字段。
  - `EquipmentInventoryProvider.tsx`：新增 `heroProgressById` 状态、经验结算接口、升级处理与快照导入导出。
  - `battleAdapters.ts`：我方模板改为读取英雄等级与成长值，不再固定 `level: 1`。
  - `BattlePage.tsx`：每场胜利结束后调用经验结算，按“参战英雄 + 敌方等级列表”发放经验。
  - `HeroPage.tsx`：属性页展示等级/经验与每级成长值，预览战斗模板改为读取真实等级。
  - `styles.css`：补齐等级信息展示样式（属性页头部与模式栏）。
