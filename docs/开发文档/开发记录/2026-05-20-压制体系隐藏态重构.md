# 2026-05-20-压制体系隐藏态重构

## 1. 任务信息

- 日期：2026-05-20
- 开发者：Codex
- 任务名称：压制体系隐藏态重构
- 需求来源：用户要求将压制值公式从简单加法/乘法升级为更复杂、可扩展的体系，并显著拉长游戏时长。

## 2. 改动目标

- 本次要解决什么问题：
  - 旧的压制推进过于线性，难以支持后续扩展。
  - 将压制系统改为“隐藏状态 + 投影公式”，让战斗、委托、月结算可以分别改写不同状态。
- 不在本次范围内的内容：
  - 不调整地图初始压制配置。
  - 不重做页面展示样式。

## 3. 代码改动清单

- 改动文件：
  - `src/data/config/suppressionProgressionConfig.ts`
  - `src/lib/suppressionSystem.ts`
  - `src/state/MapSystemProvider.tsx`
  - `docs/开发文档/05-状态管理与数据模块.md`
  - `docs/开发文档/配置文件修改指南.md`
- 每个文件改了什么（1-2 句）：
  - 新增压制隐藏态、投影评分、分段加成和月结算衰减配置。
  - 新增独立压制计算模块，统一处理战斗/委托/月结算的状态改写与可见压制值投影。
  - `MapSystemProvider` 改为维护地区基线压制和隐藏态，输出仍保持 `mapSuppression`。
