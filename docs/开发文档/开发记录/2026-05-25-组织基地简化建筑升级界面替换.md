# 2026-05-25-组织基地简化建筑升级界面替换

## 1. 任务信息

- 日期：2026-05-25
- 开发者：Codex
- 任务名称：组织基地界面简化为建筑+升级系统
- 需求来源：用户需求（取消地块显示、不同大小与形状建筑、手动放置位置系统的页面接入；保留旧代码）

## 2. 改动目标

- 本次要解决什么问题：
  - 将组织基地主界面改为更简单的建筑建造与升级列表。
  - 取消原地块画布、建筑形状占地、手动摆放交互在主页面的接入。
  - 保留原系统代码，避免删除旧实现。
- 不在本次范围内的内容：
  - 不重构 `OrganizationProvider` 的底层数据结构（仍保留 placements/revealedCells 等能力）。
  - 不删除旧地块系统代码与样式。

## 3. 代码改动清单

- 改动文件：
  - `src/pages/OrganizationPage.tsx`
  - `src/pages/OrganizationPageLegacy.tsx`
  - `src/styles.css`
  - `docs/开发文档/06-UI与样式模块.md`
- 每个文件改了什么（1-2 句）：
  - `OrganizationPage.tsx`：重写为简化版组织页，提供“可建造建筑列表 + 已建建筑升级/拆除 + 功能入口弹窗”；建造时自动分配可用位置。
  - `OrganizationPage.tsx`：二次优化布局为“顶部状态条 + 建筑目录 + 建筑管理 + 基地状态”，减少纵向堆叠并强化宽屏扫描效率。
  - `OrganizationPage.tsx`：三次调整组织基地内 UI，移除主面板图标，仅保留文字表达，降低视觉噪音。
  - `OrganizationPage.tsx`：合并基地状态、建筑数量与加成信息到顶部统一信息区；页面主体改为先展开全部建筑管理，再用分隔线连接下方建筑目录；删除测试提示、模拟经验按钮与资金展示。
  - `OrganizationPage.tsx`：将“建筑管理”和“建筑目录”统一为单一建筑列表，每类建筑只出现一次，集中显示状态、升级、功能、拆除与建造操作；可重复建筑保留继续建造入口。
  - `OrganizationPageLegacy.tsx`：保留原完整地块/形状/手动摆放实现，作为历史代码回溯入口。
  - `styles.css`：新增并调整简化组织页工作台样式（状态卡、目录网格、已建建筑网格、升级信息块），复用原主题风格但提升层级和横向铺开效果。
  - `styles.css`：将组织基地简化界面改为细线分区、低饱和背景、紧凑网格和表格式建筑条目，去掉厚卡片、强渐变和图标装饰感。
  - `styles.css`：取消建筑管理/建筑目录内部滚动，改为随页面自然展开；新增顶部统一信息区与主体分隔线样式。
  - `styles.css`：新增统一建筑列表样式，去掉当前页面对拆分式管理/目录布局的依赖。
  - `06-UI与样式模块.md`：更新组织页口径，补充简化界面入口与旧页面回溯文件说明。

- 影响页面/模块：
