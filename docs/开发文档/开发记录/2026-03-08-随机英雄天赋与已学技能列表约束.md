# 2026-03-08-随机英雄天赋与已学技能列表约束

## 1. 任务信息

- 日期：2026-03-08
- 开发者：Codex
- 任务名称：随机英雄天赋随机化与技能学习列表约束
- 需求来源：用户反馈

## 2. 改动目标

- 本次要解决什么问题：
  - 同职业随机英雄天赋固定不变，需要改为随机。
  - 英雄技能配置不应展示职业全量技能，需限制为该英雄已学技能。
  - 明确“当前技能只在随机生成时获得”，其他获取途径后续再接入。
- 不在本次范围内的内容：
  - 技能学习/升级系统完整玩法（任务、训练、消耗资源等）

- 每个文件改了什么（1-2 句）：

  - `battleLoadoutRules` 支持按 `learnedSkills` 过滤候选与校验导入配置。
  - `BattleSetupProvider/HeroPage` 接通该约束，技能下拉仅显示已学技能。
  - `heroRoster + heroGeneration.json` 改为随机天赋抽取，并按配置生成每个英雄独立已学技能清单。
  - 各职业补充了可随机的普通天赋与被动，避免同职业永远同模板。
