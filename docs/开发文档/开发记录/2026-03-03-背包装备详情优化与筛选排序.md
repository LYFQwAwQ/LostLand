# 2026-03-03-背包装备详情优化与筛选排序

## 1. 任务信息

- 日期：2026-03-03
- 开发者：Codex
- 任务名称：背包装备详情优化与筛选排序
- 需求来源：用户反馈（详情布局可读性、颜色区分、属性约束、筛选排序）

## 2. 改动目标

- 本次要解决什么问题：
  - 装备详情中“品质/品阶/等级/部位/词条/插槽”由同一行改为竖向模块展示。
  - 详情内品质、品阶及其余关键信息增加颜色区分。
  - 装备可用属性收敛到《设定/属性》文档范围，不再使用额外自定义属性。
  - 背包“装备”子界面新增筛选与排序。
- 不在本次范围内的内容：
  - 不接入真实背包数据源与持久化。
  - 不改动节点掉落、商店与锻造接入逻辑。

## 3. 代码改动清单

- 改动文件：
  - `src/pages/InventoryPage.tsx`
  - `src/styles.css`
  - `src/types/game.ts`
  - `src/data/equipmentTemplates.ts`
  - `tests/equipmentSystem.test.ts`
- 每个文件改了什么（1-2 句）：
  - `src/pages/InventoryPage.tsx`：新增筛选与排序控件（关键词/品质/品阶/部位/排序），并重构详情弹窗为竖向元信息模块。
  - `src/styles.css`：新增筛选栏和详情元信息模块样式，强化详情颜色分层与移动端适配。
  - `src/types/game.ts`：收紧 `EquipmentStatKey`，移除自由扩展键，改为属性文档限定集合。
  - `src/data/equipmentTemplates.ts`：移除非属性文档字段（如 `attack`、`castSpeed`），改用规范属性键。
  - `tests/equipmentSystem.test.ts`：同步测试模板字段，确保类型与逻辑一致。
