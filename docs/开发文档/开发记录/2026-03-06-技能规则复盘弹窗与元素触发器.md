# 2026-03-06-技能规则复盘弹窗与元素触发器

## 1. 任务信息

- 日期：2026-03-06
- 开发者：Codex
- 任务名称：英雄技能规则补齐 + 复盘弹窗化 + 元素触发器数据驱动
- 需求来源：用户需求（完成统一 TODO 中三项战斗/技能功能）

## 2. 改动目标

- 本次要解决什么问题：
  - 英雄技能配置补齐职业限制、重复冲突校验、复制/导入配置。
  - 战斗复盘改为仅在战斗结束后弹窗展示，移除战斗中常驻复盘区。
  - 元素体系改为数据驱动触发器，统一维护八系元素效果并减少引擎硬编码分支。
- 不在本次范围内的内容：
  - 不扩充职业技能库与怪物库数量。
  - 不调整掉落保底与地图压制掉落修正逻辑。
  - 不改战斗主公式与地图系统主流程。

## 3. 代码改动清单

- 改动文件：
  - `src/types/battle.ts`
  - `src/data/battleSkills.ts`
  - `src/lib/battleLoadoutRules.ts`
  - `src/state/BattleSetupProvider.tsx`
  - `src/pages/HeroPage.tsx`
  - `src/data/battleElementTriggers.ts`
  - `src/lib/battleEngine.ts`
  - `src/pages/BattlePage.tsx`
  - `src/styles.css`
- 每个文件改了什么（1-2 句）：
  - `src/types/battle.ts`：为技能定义补充 `skillPool/allowedHeroClasses/conflictSkillIds` 元数据类型。
  - `src/data/battleSkills.ts`：为天赋/主动/被动技能补职业可用范围与技能池归属，显式区分敌方技能。
  - `src/lib/battleLoadoutRules.ts`：新增技能配置规则层，提供职业技能池过滤、重复冲突校验、导入解析、配置序列化。
  - `src/state/BattleSetupProvider.tsx`：新增 `setHeroLoadout` 并统一将技能写入路径收敛到规则标准化流程。
  - `src/pages/HeroPage.tsx`：技能页接入职业筛选与冲突提示，新增“复制配置/导入配置”交互与反馈文案。
  - `src/data/battleElementTriggers.ts`：新增八系元素触发器配置表（效果类型、倍率/固定值、日志模板）。
  - `src/lib/battleEngine.ts`：将元素触发从按元素硬编码 `if/else` 改为读取触发器配置表执行。
  - `src/pages/BattlePage.tsx`：复盘改为整场结束后弹窗，战斗中与连战回合间都不再常驻/弹窗。
  - `src/styles.css`：补技能页提示/导入区样式，补战斗复盘弹窗样式。
