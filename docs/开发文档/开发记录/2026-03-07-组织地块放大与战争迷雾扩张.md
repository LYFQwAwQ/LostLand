# 组织地块放大与战争迷雾扩张

## 1. 任务信息

- 日期：2026-03-07
- 开发者：Codex
- 任务名称：组织地块尺寸放大、草地配色与升级扩张迷雾机制
- 需求来源：用户需求（地块太小、颜色偏暗、升级后可选 7x7 扩张）

## 2. 改动目标

- 本次要解决什么问题：
  - 组织地图单格尺寸过小，阅读和点击精度不足。
  - 地块整体色调偏暗，不符合草地基地的视觉预期。
  - 缺少战争迷雾与“组织升级触发地块扩张”的成长机制。
  - 扩展规则需满足“外放 + 相邻 + 不相交”，并避免非扩展模式下外圈格线干扰。
- 不在本次范围内的内容：
  - 组织评级经验来源与升级规则正式接入后端/正式数值。
  - 扩张范围预览与批量撤销等进阶编辑工具。

## 3. 代码改动清单

- 改动文件：
  - `src/types/organization.ts`
  - `src/data/organizationData.ts`
  - `src/state/OrganizationProvider.tsx`
  - `src/pages/OrganizationPage.tsx`
  - `src/styles.css`
- 每个文件改了什么（1-2 句）：
  - `organization.ts`：新增地块扩张结果类型，补齐扩张接口返回结构。
  - `organizationData.ts`：将单格尺寸调整为 `40`，新增 `initialTerritorySize`（当前 `40`）与 `expansionPatchSize`（当前 `7`），并将总画布扩展为可外放扩张空间。
  - `OrganizationProvider.tsx`：初始领地改为居中 `40x40`；扩张接口增加“必须在领地外、与现有领地相邻、且不能相交”的校验；保留升级产出扩张次数逻辑。
  - `OrganizationPage.tsx`：默认视角对齐初始 `40x40` 区域；扩展模式下允许在外圈选点扩展，建造模式下外圈保持非领地区提示。
  - `styles.css`：组织地图改为纯色像素风（草地纯绿、外圈纯灰）；非扩展模式隐藏外圈格线，扩展模式才显示外圈网格。

## 4. 影响范围

- 影响页面/模块：
  - `组织基地` 页面
  - `OrganizationProvider` 状态结构与上下文接口
- 是否影响数值平衡：
  - 是（组织升级会额外产出“扩张次数”，并限制建造区域），但仍基于模拟经验入口触发。
- 是否影响旧功能：
  - 部分影响：组织地图建造不再对全图开放，必须先扩展领地后再建造；缩放平移、建造校验、建筑点击仍可用。

## 5. 验证记录

- 手动验证路径：
  - 进入 `组织基地`，确认初始可建区域为 `40x40` 且格子放大生效，外圈为纯灰且无明显格线。
  - 点击“模拟获取组织经验”触发升级，确认出现待扩张次数并可进入扩张模式。
  - 在扩张模式点击外圈区域，确认仅当扩张块在领地外、与领地相邻、且不相交时才可扩展 `7x7` 并扣减 1 次扩张次数。
  - 在非领地区尝试建造，确认被拦截并提示先扩展。
  - 在领地区建造建筑，确认占地校验与建筑选中逻辑正常。
- 验证结果：
  - `npm run build` 通过（TypeScript + Vite 打包成功）。
- 未覆盖风险：
  - 当前升级仍由模拟按钮驱动，正式升级来源接入后需复测扩张触发次数。
