# 2026-03-08-记忆背包与唯一穿戴系统

## 1. 任务信息

- 日期：2026-03-08
- 开发者：Codex
- 任务名称：新增记忆背包子界面并改造记忆为“需拥有才可装备”
- 需求来源：用户需求（背包展示现有记忆，记忆唯一持有且不可重复装备）

## 2. 改动目标

- 本次要解决什么问题：
  - 在背包页新增“记忆”子界面，展示当前已有记忆并展示装备归属。
  - 将英雄记忆从“占位下拉”改为“背包驱动穿戴”：只有已拥有记忆可装备，且同一记忆全局唯一。
  - 统一记忆状态归属到背包 Provider，和装备规则保持一致的全局唯一约束。
- 不在本次范围内的内容：
  - 不实现记忆的正式掉落/任务获取流程（当前仅提供默认初始拥有记忆）。
  - 不改动战斗内记忆效果计算链路（当前仍为展示与配置层）。

## 3. 代码改动清单

- 改动文件：
  - `src/types/game.ts`
  - `src/data/heroMemories.ts`
  - `src/state/EquipmentInventoryProvider.tsx`
  - `src/state/BattleSetupProvider.tsx`
  - `src/pages/HeroPage.tsx`
  - `src/pages/InventoryPage.tsx`
  - `src/styles.css`
- 每个文件改了什么（1-2 句）：
  - `src/types/game.ts`：新增 `InventoryMemoryStack` 记忆库存类型。
  - `src/data/heroMemories.ts`：新增记忆全量词典与默认初始拥有列表。
  - `src/state/EquipmentInventoryProvider.tsx`：新增记忆库存、记忆穿戴映射、唯一归属校验、快照导入导出字段。
  - `src/state/BattleSetupProvider.tsx`：移除记忆状态，仅保留编队与技能配置状态。
  - `src/pages/HeroPage.tsx`：记忆页改为“背包可用记忆列表 + 装备/卸下”，并显示“已被谁装备”。
  - `src/pages/InventoryPage.tsx`：新增“记忆”子界面，支持关键词、职业筛选和状态展示（无需数量）。
  - `src/styles.css`：新增背包记忆卡片样式与英雄页记忆库存面板样式。

## 4. 影响范围

- 影响页面/模块：
  - 背包页（新增记忆子界面）
  - 英雄页记忆标签（从占位选择改为库存驱动装备）
  - 全局状态层（记忆状态迁移至 EquipmentInventoryProvider）
  - 队伍预设（记忆状态随 equipment 快照保存/加载）

- 是否影响旧功能：
  - 是（记忆穿戴入口与状态归属发生变更，旧占位逻辑被替换）。
