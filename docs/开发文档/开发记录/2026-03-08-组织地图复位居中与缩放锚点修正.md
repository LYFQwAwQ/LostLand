# 组织地图复位居中与缩放锚点修正

## 1. 任务信息

- 日期：2026-03-08
- 开发者：Codex
- 任务名称：组织地图复位居中与缩放手感修正
- 需求来源：用户反馈（复位未回到已拥有地块中心，缩放手感异常）

## 2. 改动目标

- 本次要解决什么问题：
  - `复位视角` 未按当前领地中心定位，扩展后复位体验偏差明显。
  - 滚轮缩放直接改倍率，导致视角朝左上角漂移，缩放手感不自然。
- 不在本次范围内的内容：
  - 领地扩展规则与扩展次数来源。

## 3. 代码改动清单

- 改动文件：
  - `src/pages/OrganizationPage.tsx`
- 每个文件改了什么（1-2 句）：
  - 新增领地包围盒计算与 `centerOnOwnedTerritory()`，复位时基于当前已拥有地块中心居中。
  - 缩放逻辑统一改为 `applyZoom()` 锚点缩放：滚轮按鼠标位置缩放，按钮按视口中心缩放，并同步重算偏移避免视角漂移。
  - 首次进入组织页时在视口尺寸可用后自动居中一次，减少初始偏移误差。

## 4. 影响范围

- 影响页面/模块：
  - `组织基地` 页面地图相机交互（复位与缩放）。
- 是否影响数值平衡：
  - 否。
- 是否影响旧功能：
  - 否，建造/扩展/平移规则不变。

## 5. 验证记录

- 手动验证路径：
  - 在地图中先扩展若干块领地后点击 `复位视角`，确认镜头回到当前领地中心。
  - 使用滚轮在不同鼠标位置缩放，确认缩放围绕锚点进行且不再明显飘移。
  - 使用 `+/-` 按钮缩放，确认以视口中心为锚点，连续缩放更平稳。
- 验证结果：
  - `npm run build` 通过（TypeScript + Vite 打包成功）。
- 未覆盖风险：
  - 极端缩放倍率下的拖拽边界体验仍依赖玩家手动复位，后续可按需补“边界吸附”。
