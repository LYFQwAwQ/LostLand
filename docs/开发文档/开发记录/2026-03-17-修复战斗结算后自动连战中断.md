# 2026-03-17-修复战斗结算后自动连战中断

## 1. 任务信息

- 日期：2026-03-17
- 开发者：Codex
- 任务名称：修复战斗结算后自动连战中断
- 需求来源：用户反馈（“完成当场战斗后不会自动继续战斗”）

## 2. 改动目标

- 本次要解决什么问题：
  - 战斗胜利结算后，掉落入包与任务进度回写会触发 Provider 更新，间接导致战斗页 `initialRuntime` 重算并重置会话，自动连战在衔接前被中断。
  - 恢复“胜利后自动进入下一场，沿用存活单位 HP/MP”的连战闭环。
- 不在本次范围内的内容：
  - 不调整战斗公式、掉落概率、任务推进规则。
  - 不新增连战开关或新配置参数。

## 3. 代码改动清单

- 每个文件改了什么（1-2 句）：
  - `BattlePage` 去除基于 `initialRuntime` 的被动重置，改为仅在 `battleSeed`/节点变化时重置战斗会话，避免结算回写引发的无关重置打断自动连战；同步修正文案为“胜利后自动继续下一场”。
  - 战斗模块文档补充连战会话重置约束，明确回写链路不应重置 `runtime`。
