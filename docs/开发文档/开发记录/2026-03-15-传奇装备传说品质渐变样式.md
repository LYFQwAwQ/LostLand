# 开发记录：传奇装备传说品质渐变样式

## 1. 任务信息

- 日期：2026-03-15
- 开发者：Codex
- 任务名称：传说与圣铸品质颜色区分（传说独立渐变）
- 需求来源：用户需求（传说与圣铸不能同色）

## 2. 改动目标

- 本次要解决什么问题：
  - 传奇装备显示“传说”时，使用区别于普通“圣铸”的视觉样式。
  - 通过彩色渐变 + 轻微流动动画突出传奇专属品质。
- 不在本次范围内的内容：
  - 不改品质枚举、掉落权重、品质数值逻辑。

## 3. 代码改动清单

- 改动文件：
  - `src/pages/InventoryPage.tsx`
  - `src/pages/HeroPage.tsx`
  - `src/styles.css`
- 每个文件改了什么（1-2 句）：
  - `InventoryPage.tsx`：新增按装备类型返回品质 class 的方法；传奇装备品质使用 `quality-legendary-exclusive`。
  - `HeroPage.tsx`：装备选择列表和悬浮详情的品质徽章改为使用同一套传奇专属 class 判断。
  - `styles.css`：新增 `quality-legendary-exclusive` 渐变文字与徽章边框样式，补充动画与 `prefers-reduced-motion` 兼容。

## 4. 影响范围

- 影响页面/模块：

- 是否影响数值平衡：否
- 是否影响旧功能：否（仅显示样式与 class 选择逻辑）
