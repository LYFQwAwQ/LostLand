# 2026-03-17 人族疆域固定地图与实体节点接入

## 1. 任务信息

- 日期：2026-03-17
- 开发者：Codex
- 任务名称：人族疆域固定地图与实体节点接入
- 需求来源：用户提出“固定地图替换随机地图、实体节点替代模板显示、保留旧随机系统代码、接入人族疆域并删除旧两疆域、新增异兽种族与节点固定敌人池规则”。

## 2. 改动目标

- 本次要解决什么问题：
  - 将当前可游玩地区切换为固定地图拓扑，并接入人族疆域。
  - 节点从模板编码展示（ST/BL）改为实体类型展示。
  - 战斗节点改为“节点敌人池固定 + 战斗内按权重抽样”，并支持人数正态分布。
  - 新增异兽（aberrant）敌人种族并接入掉落系统。
- 不在本次范围内的内容：
  - 不删除旧随机拓扑与模板相关代码，仅从当前入口链路上断开。
  - 不扩展到其他大陆开放与多疆域并行运营。

## 3. 代码改动清单

- `src/config/world/worldHierarchy.json`
  - 中央大陆收敛为 `human-territory` 单疆域，接入 4 个新地区。
- `src/data/fixedRegionTopologies.ts`
  - 新增固定地区拓扑定义（节点、边、实体类型、节点战斗池、人数分布）。
- `src/data/worldMapData.ts`
  - 地区生成入口改为“固定拓扑优先，随机拓扑回退”。
- `src/types/game.ts`
  - 扩展 `RegionNode`：新增 `entityType` 与 `battleConfig`。
- `src/data/battleUnits.ts`
  - 新增异兽敌人原型池；敌方生成支持按 `sourceNodeId` 读取固定节点战斗池。
- `src/data/battleDrops.ts`
  - 材料与装备模板掉落池扩展到四种族（含异兽）。
- `src/lib/battleAdapters.ts`
  - 敌方模板构建新增 `sourceNodeId` 透传。
- `src/lib/bulletinMissionSystem.ts`
  - 任务扫描敌人池时按真实节点 ID 生成，确保与固定节点敌人池一致。
- `src/pages/WorldMapPage.tsx`
  - 地图标签/测距/tooltip 改为显示“地名 + 实体类型”。
- `src/pages/BattlePage.tsx`
  - 战斗页标题改为显示节点实体类型，不再展示模板编码。
