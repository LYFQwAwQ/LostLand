# 2026-03-08-随机英雄技能抽取数量与同职业天赋去重

## 1. 任务信息

- 日期：2026-03-08
- 开发者：Codex
- 任务名称：随机英雄技能数量收敛与同职业天赋随机性修正
- 需求来源：用户反馈

## 2. 改动目标

- 本次要解决什么问题：
  - 普通随机英雄在部分职业上会拿到几乎全量主动技能，和“随机初始技能”预期不一致。
  - 同次启动里若出现同职业随机英雄，天赋重复概率过高，体感上像“固定模板”。
  - 需要继续保持“技能选择仅来自已学技能列表”的约束。
- 不在本次范围内的内容：
  - 非随机来源的技能获取流程（训练/任务/消耗资源等正式玩法）

## 3. 代码改动清单

- 改动文件：
  - `src/data/heroRoster.ts`
  - `src/data/config/heroGeneration.json`
  - `docs/开发文档/04-英雄与队伍模块.md`
  - `docs/开发文档/配置文件修改指南.md`
- 每个文件改了什么（1-2 句）：
  - `heroRoster.ts`：新增“同职业普通随机英雄优先不重复天赋”逻辑；主动技能抽取支持必带列表（`alwaysIncludeActiveSkillIds`）。
  - `heroGeneration.json`：普通随机英雄默认主动抽取数从 `7` 调整为 `5`；新增 `alwaysIncludeActiveSkillIds` 并默认包含 `basic_attack`。
  - 文档补充了上述规则与可调参数说明。

## 4. 影响范围

- 影响页面/模块：
  - 启动英雄生成（`createStartupHeroes`）
  - 英雄页技能配置（候选仍受 `learnedSkills` 约束）
  - 队伍/战斗初始可用技能组合
- 是否影响数值平衡：
  - 是。普通随机英雄初始技能覆盖率下降，早期战斗表现更依赖随机组合。
- 是否影响旧功能：
  - 会改变“普通随机英雄通常接近全主动技能”的旧体验；传奇英雄与固定测试英雄不受本次规则变更影响。

## 5. 验证记录

- 手动验证路径：
  - 连续刷新应用，查看同职业普通随机英雄天赋是否出现轮换。
  - 检查普通随机英雄初始主动技能数量是否为配置值（默认 5），且包含 `basic_attack`。
  - 在英雄技能配置页确认候选只展示该英雄已学技能。
- 验证结果：
  - 构建通过，生成逻辑与配置读取正常。
- 未覆盖风险：
  - 尚未做大样本概率统计；短样本下仍可能观察到同职业同天赋重复（当天赋池耗尽或随机回落时）。
