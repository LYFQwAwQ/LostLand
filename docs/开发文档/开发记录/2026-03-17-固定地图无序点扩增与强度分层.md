# 2026-03-17-固定地图无序点扩增与强度分层

## 1. 任务信息

- 日期：2026-03-17
- 开发者：Codex
- 任务名称：固定地图无序点扩增与强度分层
- 需求来源：用户反馈“每个地区无序地点偏少，需要增加，并做出强度分层”。

## 2. 改动目标

- 本次要解决什么问题：
  - 提高四个固定地区的无序节点数量。
  - 对无序节点建立清晰的强度梯度（BL3 < BL2 < BL1）。
- 不在本次范围内的内容：
  - 不改动旧随机地图系统接线状态。
  - 不改动稳定节点功能入口规则。

## 3. 代码改动清单

- `src/data/fixedRegionTopologies.ts`
  - 新增分层人数分布参数：`FRONTIER_COUNT_DISTRIBUTION`、`CONTESTED_COUNT_DISTRIBUTION`、`CORE_COUNT_DISTRIBUTION`。
  - 四个地区无序节点均扩增至 5 个（BL1=1、BL2=2、BL3=2）。
  - 新增无序节点：
    - `rc-blacktide-sanctum`、`rc-brine-reed-bog`
    - `ih-hoarfang-warren`
    - `ae-sandvice-burrow`
    - `mw-rotroot-mangrove`
  - 同步补充新增节点路网连线与战斗敌人池。
  - 将无序节点战斗抽样统一接入分层分布：BL3 前沿层、BL2 争夺层、BL1 核心层。

## 4. 影响范围

- 影响页面/模块：
  - 世界地图固定拓扑展示、节点战斗遭遇、任务敌人可见池。
- 是否影响数值平衡：
  - 是。无序节点数量与分层强度提升后，边界区域战斗密度与整体难度会提高。
- 是否影响旧功能：
  - 否。旧随机系统代码与模板体系保持保留。
