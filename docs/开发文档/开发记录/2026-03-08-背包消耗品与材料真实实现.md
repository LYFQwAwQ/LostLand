# 2026-03-08-背包消耗品与材料真实实现

## 1. 任务信息

- 日期：2026-03-08
- 开发者：Codex
- 任务名称：背包中的消耗品和材料由占位接口改为真实实现
- 需求来源：用户需求（消耗品可示例实现并加入 TODO，材料直接接怪物掉落表）

## 2. 改动目标

- 本次要解决什么问题：
  - 背包页“消耗品/材料”子界面不再显示占位文案，改为可筛选、可排序的真实列表。
  - 材料库存直接使用怪物掉落表词典，并在战斗胜利后把材料掉落写入全局背包。
  - 消耗品提供可运行的示例库存实现，并明确后续正式接入 TODO。
- 不在本次范围内的内容：
  - 不调整装备生成与穿戴逻辑。
  - 不实现消耗品在战斗中的使用与扣减流程。
  - 不接入地图压制对掉落规则的额外修正。

## 3. 代码改动清单

- 改动文件：
  - `src/types/game.ts`
  - `src/types/battle.ts`
  - `src/data/battleDrops.ts`
  - `src/data/consumables.ts`
  - `src/state/EquipmentInventoryProvider.tsx`
  - `src/pages/BattlePage.tsx`
  - `src/pages/InventoryPage.tsx`
  - `src/styles.css`
- 每个文件改了什么（1-2 句）：
  - `src/types/game.ts`：新增资源背包类型（稀有度、消耗品库存、材料库存）。
  - `src/types/battle.ts`：材料稀有度改为复用 `game` 侧资源稀有度类型。
  - `src/data/battleDrops.ts`：新增材料掉落词典导出 `getMaterialDropCatalog()`，用于背包材料来源。
  - `src/data/consumables.ts`：新增消耗品示例库存数据，并加 TODO 注释说明后续接正式来源。
  - `src/state/EquipmentInventoryProvider.tsx`：扩展为“装备 + 材料 + 消耗品”统一状态，新增 `collectBattleDrops()` 把战斗材料写入库存，并支持快照导入导出。
  - `src/pages/BattlePage.tsx`：战斗胜利结算时调用 `collectBattleDrops()`，自动入库材料。
  - `src/pages/InventoryPage.tsx`：替换消耗品/材料占位 UI，新增筛选、排序、稀有度过滤和库存展示。
  - `src/styles.css`：新增资源列表卡片和 TODO 提示样式，并补移动端适配。
