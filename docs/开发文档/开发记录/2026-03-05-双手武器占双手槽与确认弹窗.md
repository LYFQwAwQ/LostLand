# 2026-03-05-双手武器占双手槽与确认弹窗

## 1. 任务信息

- 日期：2026-03-05
- 开发者：Codex
- 任务名称：双手武器占双手槽与确认弹窗
- 需求来源：用户需求（双手武器占用两个手部槽位，并在冲突时弹窗确认）

## 2. 改动目标

- 本次要解决什么问题：
  - 手部装备槽可选择双手武器。
  - 双手武器装备时占用左右两个手部槽位。
  - 当另一手已有装备时，弹出确认窗，确认后移除另一手装备并装备双手武器。
- 不在本次范围内的内容：
  - 不实现双手武器专属词条机制。
  - 不改背包筛选逻辑（仍按部位筛选）。

## 3. 代码改动清单

- 改动文件：
  - `src/pages/HeroPage.tsx`
  - `src/state/EquipmentInventoryProvider.tsx`
  - `src/lib/equipmentCatalog.ts`
  - `src/data/equipmentTemplates.ts`
  - `src/styles.css`
- 每个文件改了什么（1-2 句）：
  - `HeroPage.tsx`：手部槽位候选扩展为单手+双手，并新增“双手武器冲突确认弹窗”。
  - `EquipmentInventoryProvider.tsx`：支持双手武器占两手槽位、同英雄槽位移动、冲突替换控制（`forceReplaceHand`）。
  - `equipmentCatalog.ts`：新增手部槽位辅助函数（识别手部槽位、获取另一手槽位）。
  - `equipmentTemplates.ts`：新增双手武器模板（巨剑/长矛）进入掉落池。
  - `styles.css`：新增双手冲突确认弹窗样式。
