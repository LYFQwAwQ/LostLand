# 2026-03-03-背包界面与装备详情弹窗

## 1. 任务信息

- 日期：2026-03-03
- 开发者：Codex
- 任务名称：背包界面与装备详情弹窗
- 需求来源：用户需求（先落地背包页面，并以装备子界面完成展示与详情）

## 2. 改动目标

- 本次要解决什么问题：
  - 新增背包页面与入口。
  - 在背包中新增“装备”子界面，支持缩略展示与点击查看详情。
  - 按品质与品阶显示不同颜色，并引入内部评分分档控制卡片颜色层级（分数不对外展示）。
- 不在本次范围内的内容：
  - 不接入正式背包存储、掉落链路与穿戴逻辑。
  - 消耗品/材料子界面仅为占位。

- 改动文件：

- 每个文件改了什么（1-2 句）：
  - `src/App.tsx`：新增 `/inventory` 路由。

  - `src/styles.css`：新增 `inventory-*` 样式、品质/品阶颜色、卡片分档色与弹窗样式。

## 5. 验证记录

- 手动验证路径：
  - 侧边栏点击“背包”进入 `/inventory`。
  - 背包页切换到“装备”子界面，查看缩略卡颜色和品质/品阶颜色。
  - 点击任意装备，检查半透明弹窗中详细属性与颜色标识。
  - 点击遮罩或右上角关闭按钮，确认弹窗关闭。
- 验证结果：
  - 构建通过：`npm run build`。
  - 既有装备单测通过：`node --experimental-strip-types --test --test-isolation=none tests/equipmentSystem.test.ts`（7/7）。
- 未覆盖风险：
  - 暂未与真实背包数据源联调；
  - 当前“刷新样本”为调试用途，后续接入真实仓库后应替换。
