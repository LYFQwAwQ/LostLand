# 2026-03-12-任务系统接取上限与任务大厅

## 1. 任务信息

- 日期：2026-03-12
- 开发者：Codex
- 任务名称：任务系统接取上限与组织任务大厅
- 需求来源：用户提出的功能需求

## 2. 改动目标

- 本次要解决什么问题：
  - 布告栏任务新增“同时可接取任务上限”限制，默认上限 4。
  - 新增组织功能建筑“任务大厅”，点击后进入界面查看当前已接取任务（进行中 / 可提交）。
- 不在本次范围内的内容：
  - 任务上限成长来源（如建筑等级/科技）仅预留接口，暂未接入正式成长链路。
  - 其他功能建筑（铁匠铺/远征/图书馆）仍保持占位界面。

## 3. 代码改动清单

- 改动文件：
  - `src/data/config/bulletinMissionConfig.ts`
  - `src/state/MapSystemProvider.tsx`
  - `src/pages/NodeActionPage.tsx`
  - `src/data/organizationData.ts`
  - `src/pages/OrganizationPage.tsx`
  - `src/styles.css`
- 每个文件改了什么（1-2 句）：
  - `bulletinMissionConfig.ts`：新增全局任务接取上限配置与 `getBulletinMissionAcceptedLimit(extraCapacity)` 接口，默认上限设为 4。
  - `MapSystemProvider.tsx`：新增已接取任务计数/上限对外状态、跨地区已接任务聚合接口，并在 `acceptBulletinMission` 中加入上限校验与失败原因回传。
  - `NodeActionPage.tsx`：布告栏新增“已接取任务数/上限”展示，领取按钮在达到上限后禁用并使用 Provider 返回原因提示。
  - `organizationData.ts`：新增唯一功能建筑“任务大厅”定义（可点击进入功能界面）。
  - `OrganizationPage.tsx`：任务大厅弹窗改为实际任务界面，展示已接任务列表、地区信息、类型、状态、目标与进度。
  - `styles.css`：补充任务大厅列表与卡片样式。

## 4. 影响范围

- 影响页面/模块：
  - 节点布告栏页（任务领取限制展示与校验）
  - 组织页（任务大厅建筑与任务查看界面）
  - 地图任务状态管理（MapSystemProvider）
- 是否影响数值平衡：
  - 是。可同时接取任务数量从“无限制”变为“默认上限 4”。
- 是否影响旧功能：
  - 是。旧流程可继续使用，但布告栏领取任务会在达到上限后被阻止。
