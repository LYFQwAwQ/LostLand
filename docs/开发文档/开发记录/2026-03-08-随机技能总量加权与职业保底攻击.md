# 2026-03-08-随机技能总量加权与职业保底攻击

## 1. 任务信息

- 日期：2026-03-08
- 开发者：Codex
- 任务名称：随机技能数量改为总量加权并接入职业保底攻击
- 需求来源：用户反馈

## 2. 改动目标

- 本次要解决什么问题：
  - 随机英雄技能数量不应等概率抽取，需要“主动+被动总数越多概率越低”。
  - 保底攻击需要固定占用 1 个主动槽位，并且按职业独立配置。
- 不在本次范围内的内容：
  - 技能获取正式玩法（训练/任务/资源消耗）

## 3. 代码改动清单

- 改动文件：
  - `src/data/heroRoster.ts`
  - `src/data/config/heroGeneration.json`
  - `docs/开发文档/04-英雄与队伍模块.md`
  - `docs/开发文档/配置文件修改指南.md`
- 每个文件改了什么（1-2 句）：
  - `heroRoster.ts`：新增主动/被动数量组合的加权抽样（总量越大权重越低），并将保底主动收敛为“固定 1 槽”。
  - `heroGeneration.json`：为各职业配置 `fixedGuaranteedActiveSkillId`（圣骑：`paladin_holy_blade`；法师：`mage_arcane_bolt`；游侠：`ranger_quick_shot`），并配置 `totalCountWeightDecay`。
  - 文档补充了新字段语义、兼容规则与当前行为说明。

## 4. 影响范围

- 影响页面/模块：
  - 启动英雄生成（普通随机英雄的已学技能数量与组合分布）
  - 英雄技能配置候选列表（由 `learnedSkills` 驱动，候选数量随抽样变化）
- 是否影响数值平衡：
  - 是。技能总量分布向“更少技能”侧偏移。
- 是否影响旧功能：
  - 会改变此前区间内近似均匀分布的结果；现在总技能数高的样本更少见。

## 5. 验证记录

  - 检查各职业是否稳定带上各自保底主动且仅占 1 个主动槽。
- 验证结果：
