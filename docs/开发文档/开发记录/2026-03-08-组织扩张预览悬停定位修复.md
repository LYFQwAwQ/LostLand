# 组织扩张预览悬停定位修复

## 1. 任务信息

- 日期：2026-03-08
- 开发者：Codex
- 任务名称：扩张预览不显示修复
- 需求来源：用户反馈（扩张模式内外都不显示预览范围）

## 2. 改动目标

- 本次要解决什么问题：
  - 扩张预览依赖格子 `mouseenter`，在裁剪渲染与事件透传场景下触发不稳定，导致预览消失。
- 不在本次范围内的内容：
  - 扩张规则与预览配色调整。

## 3. 代码改动清单

- 改动文件：
  - `src/pages/OrganizationPage.tsx`
- 每个文件改了什么（1-2 句）：
  - 新增 `resolveCellFromClient()`，通过鼠标坐标反算当前网格坐标。
  - `onViewportMouseMove` 改为统一更新 `hoveredCell`，并同步更新悬浮信息卡；`onMouseLeave` 清空悬停状态，保证扩张预览稳定触发。

## 4. 影响范围

- 影响页面/模块：
  - `组织基地` 页面扩张与建造模式悬停反馈。
- 是否影响数值平衡：
  - 否。
- 是否影响旧功能：
  - 否，点击建造/扩张逻辑不变，仅修复悬停感知来源。

## 5. 验证记录

  - 离开地图区域后返回，确认预览状态正常恢复。
