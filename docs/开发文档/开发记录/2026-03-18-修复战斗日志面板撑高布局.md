# 2026-03-18-修复战斗日志面板撑高布局

## 1. 任务信息

- 日期：2026-03-18
- 开发者：Codex
- 任务名称：修复战斗日志面板撑高布局
- 需求来源：用户反馈（右侧战斗日志增加时，左侧阵型与行动队列被拉长并出现大面积空白）

## 2. 改动目标

- 本次要解决什么问题：
  - 右侧战斗日志在日志增长时持续拉高布局，导致左侧主战斗区被动拉伸。
  - 战斗日志应保持在可滚动面板内增长，而不是整体页面高度不断增长。
- 不在本次范围内的内容：
  - 不改动战斗引擎日志生成内容与频率。
  - 不改动战斗结算、复盘、掉落等业务逻辑。

## 3. 代码改动清单

- 改动文件：
  - `src/styles.css`
  - `docs/开发文档/07-战斗系统模块.md`
  - `docs/开发文档/README.md`
- 每个文件改了什么（1-2 句）：
  - `styles.css` 为战斗布局与日志卡片补齐高度约束：`battle-layout` 顶部对齐、`battle-sidebar` 使用 `minmax(0, 1fr)`、`battle-log-card` 增加 `max-height` 与 `overflow: hidden`、`battle-log-list` 改为 `flex: 1` + `overflow: auto`。
  - 战斗模块文档补充“日志面板固定高度滚动，不应撑高整体布局”的行为说明。
  - 文档总览新增本条开发记录索引。

## 4. 影响范围

- 影响页面/模块：
  - 战斗页布局（右侧日志面板与左右主区高度关系）。
- 是否影响数值平衡：
  - 否。
- 是否影响旧功能：
  - 否（仅样式与布局行为修复）。
