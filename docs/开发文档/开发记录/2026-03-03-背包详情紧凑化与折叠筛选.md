# 2026-03-03-背包详情紧凑化与折叠筛选

## 1. 任务信息

- 日期：2026-03-03
- 开发者：Codex
- 任务名称：背包详情紧凑化与折叠筛选
- 需求来源：用户反馈（详情不够紧凑、品质文案语义、筛选交互）

## 2. 改动目标

- 本次要解决什么问题：
  - 去掉详情中臃肿的小卡片信息框，改为紧凑竖排并用虚线分隔。
  - 等级并入标题行，部位紧邻名称并在类型文案之前。
  - 品质文案改为名称（普通/优秀/稀有/史诗/传说/神话），颜色仅做标识。
  - 标签筛选改为可折叠分组，默认只展开品质和品阶，支持一键清空。
- 不在本次范围内的内容：
  - 不改动装备生成算法和掉落接入逻辑。

## 3. 代码改动清单

- 改动文件：
  - `src/pages/InventoryPage.tsx`
  - `src/styles.css`
  - `src/lib/equipmentSystem.ts`
- 每个文件改了什么（1-2 句）：
  - `src/pages/InventoryPage.tsx`：详情结构重排为主信息融合布局；新增筛选分组折叠状态和交互。
  - `src/styles.css`：新增折叠组样式，详情元信息改为竖向紧凑列表与虚线分隔。
  - `src/lib/equipmentSystem.ts`：品质文案改为名称制，并新增品质颜色名称映射。
