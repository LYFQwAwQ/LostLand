# 2026-03-05-英雄装备栏接通背包穿戴与饰品类型

## 1. 任务信息

- 日期：2026-03-05
- 开发者：Codex
- 任务名称：英雄装备栏接通背包穿戴与饰品类型
- 需求来源：用户需求（移除调试面板、改为背包选择穿戴、补饰品类型与职业穿戴规则）

## 2. 改动目标

- 本次要解决什么问题：
  - 删除英雄装备页底部的装备生产调试面板。
  - 将英雄装备栏从静态占位改为接入装备系统数据。
  - 装备流程改为“先生成背包，再点击槽位选择同类型装备穿戴”。
  - 新增装备槽位 `accessory` 与子类型 `ring/necklace/bracelet`。
  - 固化职业穿戴规则：
    - 圣骑士：1头盔 + 1护甲 + 2护腿 + 2护手 + 2手部 + 3饰品
    - 元素法师：1施法核心 + 5施法媒介（界面称符文）+ 1头盔 + 1护甲 + 3饰品
- 不在本次范围内的内容：
  - 不接入全局存档/跨页面共享背包状态。
  - 不接入节点掉落、商店和经济链路。

  - `PaladinGearBoard.tsx`、`MageGearBoard.tsx`：装备槽位支持选中态与已穿戴装备展示（名称、品质、品阶）。

  - `equipmentCatalog.ts`：集中维护槽位/子类型中文映射和职业装备槽位定义、职业装备类型摘要。

  - `InventoryPage.tsx`：改为复用统一装备词典映射，确保与英雄装备页口径一致。
  - `game.ts`：扩展 `EquipmentSlot` 与 `EquipmentSubtype`，新增饰品相关类型。
  - `styles.css`：删除调试面板样式，新增英雄装备背包面板样式和槽位选中态样式。

## 5. 验证记录

- 手动验证路径：
  - `英雄殿堂 -> 装备体系`：
    - 点击任一槽位，确认下方只显示同类型背包装备；
    - 选择装备后槽位展示已更新；
