# 04. 英雄与队伍模块

## 1. 模块职责

- 英雄页：属性、装备、记忆三大标签页展示。
- 英雄页：新增独立“技能配置”标签，支持天赋/主动/被动槽位编辑。
- 英雄页：记忆标签支持“从背包记忆中穿戴/卸下”。
- 记忆系统：记忆按“装备”逻辑生效，仅可装备已拥有记忆；每个记忆全局唯一，不可被多个英雄重复装备。
- 记忆 UI：保持“左信息 + 右立绘”结构，通过“查看记忆库存”按钮弹出记忆列表进行装备。
- 英雄数据：固定英雄 + 启动时随机英雄（默认 2 名），随机英雄支持小概率传奇英雄。
- 技能获取：当前仅“创建随机英雄时生成初始已学技能列表”，后续获取途径待扩展。
- 英雄装备页：背包装备生成、槽位选择、同类型装备穿戴交互。
- 队伍页：前后排 6 格可编辑编队（前排 3 + 后排 3），支持拖拽换位。
- 队伍页：支持 10 套全量预设（编队 + 技能槽位 + 装备 + 记忆穿戴）保存/加载。

## 3. 标签与 URL 约定

- 路由：`/hero/:heroId`
- 标签通过 query 参数控制：`?tab=stats|gear|skills|memory`
- `HeroPage` 内部默认 tab 为 `stats`

## 4. 常见修改任务

## 4.1 新增英雄

默认英雄列表由 `src/data/mockData.ts -> createStartupHeroes()` 提供（不再直接手写数组）。

常见改法：

- 固定英雄：修改 `src/data/heroRoster.ts` 的 `BASE_FIXED_HEROES`
- 普通随机英雄：修改 `src/data/config/heroGeneration.json`
- 传奇英雄：修改 `src/data/config/legendaryHeroes.json`
- 若要在左侧导航直达，需同步修改 `src/components/layout/MainLayout.tsx`

## 4.2 新增职业装备布局

1. 新增组件（仿照 `PaladinGearBoard.tsx` / `MageGearBoard.tsx`）
2. 在 `HeroPage.tsx` 的 `HeroGearContent` 中按 `heroClass` 分流渲染
3. 在 `src/types/game.ts` 扩展 `HeroClass`

## 4.3 调整队伍页结构

直接修改 `src/pages/TeamPage.tsx`：

- 编队格布局与站位规则（前排/后排）
- 拖拽规则（英雄池 -> 槽位、槽位 -> 槽位交换）
- 预设管理面板（10 套预设的命名、保存、加载、清空）
- 英雄分配面板展示方式（点击分配与拖拽并存）

## 4.4 调整技能槽位配置界面

修改 `src/pages/HeroPage.tsx`：

- `HeroSkillsContent` 与 `HeroSkillLoadoutEditor` 的渲染结构
- 天赋/主动/被动槽位交互（下拉、重置）
- 天赋槽位固定，不允许手动修改（导入配置也不会覆盖天赋）
- 天赋槽位改为左侧信息卡展示（名称 + 稀有度颜色 + 描述）
- 职业可用技能过滤（公用池 + 本职业池，不显示敌方技能）
- 候选技能进一步收敛到当前英雄 `learnedSkills`（未学会技能不显示、不允许导入后生效）
- 重复技能冲突校验提示（重复即冲突，自动清空后写回）
- 主动/被动下拉候选去重（其他槽位已选技能不再出现在当前候选中）
- 主动技能槽位显示当前技能权重（`baseWeight`）
- 配置复制/导入（JSON 文本）
- 技能悬停详情浮层（鼠标移入槽位选择框显示技能说明与关键参数）
- 标签页入口（`skills`）

修改 `src/state/BattleSetupProvider.tsx`：

- 全局技能槽位状态结构
- `setHeroLoadout / setHeroTalent / setHeroActiveSkill / setHeroPassiveSkill` 写入逻辑（统一走规则标准化）

## 4.4 装备穿戴交互（当前实现）

1. 打开任一英雄页并切到 `装备体系` 标签。
2. 点击右侧装备栏任意槽位（高亮表示当前选中槽位）。
3. 系统弹出“装备选择窗口”，展示该槽位类型在全局背包中的全部装备。
4. 鼠标悬停在装备项上会显示半透明“装备详情浮层”（基础属性、附加词条、品阶品质、插槽等）。
5. 可穿戴装备可直接点击装备；若该装备已被其他英雄穿戴则置灰不可选。
6. 点击“刷新背包”会重新生成背包样本，并自动清除失效穿戴引用。
7. 同一件装备在全局仅允许被一个英雄的一个槽位穿戴；背包页会显示“已装备：英雄名”。
8. 圣骑士手部槽位支持单手/双手同池选择；当另一手已装备时，装备双手武器会弹确认窗（确认后移除另一手装备）。

## 5. 注意事项

- 英雄页与背包页共享同一套全局背包/穿戴状态（`EquipmentInventoryProvider`），避免了页面间状态分叉。
- 队伍编队与技能槽位共享同一套全局战斗配置状态（`BattleSetupProvider`），并直接驱动战斗页。
- 队伍预设保存的是“全量构筑快照”：编队、技能槽位、装备穿戴映射、记忆穿戴状态。
- 记忆穿戴状态统一由 `EquipmentInventoryProvider` 维护（背包中有才可装备、同记忆不可重复穿戴）。
- `hero.learnedSkills` 是技能配置界面的硬约束来源；修改随机英雄技能数量优先改 `heroGeneration.json` 的 `activePickCountRange/passivePickCountRange`。
- 同一次启动中，若生成出同职业普通随机英雄，会优先避免天赋重复（测试期逻辑；正式版计划移除，见项目 TODO）。
- `standardLoadoutPools.fixedGuaranteedActiveSkillId` 配置“固定保底主动技能”，并固定占用 1 个主动槽位（按职业独立配置）。
- 预设持久化走浏览器 `localStorage`（key: `lostland.team.presets.v2`），更改结构需同步做兼容处理。
- `MageGearBoard` 采用几何坐标计算槽位，改布局时优先改半径常量和角度，不建议手写像素偏移。
- `RangerGearBoard` 使用绝对定位槽位布局，改布局优先调 `ranger-slot-*` 的百分比坐标。
- 装备系统以 `equipmentSystem + equipmentTemplates` 为准；新增槽位或子类型时，需同步 `equipmentCatalog` 与背包筛选文案。
