# 04. 英雄与队伍模块

## 1. 模块职责

- 英雄页：属性、装备、记忆三大标签页展示。
- 英雄页：新增独立“技能配置”标签，支持天赋/主动/被动槽位编辑。
- 英雄装备页：背包装备生成、槽位选择、同类型装备穿戴交互。
- 队伍页：前后排 6 格可编辑编队（前排 3 + 后排 3）。

## 2. 关键文件

- `src/pages/HeroPage.tsx`
  - 标签切换、英雄切换、各分区内容渲染
- `src/pages/TeamPage.tsx`
  - 队伍配置页面（可编辑站位与英雄分配）
- `src/state/BattleSetupProvider.tsx`
  - 全局战斗配置状态（编队 + 英雄技能槽位），并在写入时统一做职业/冲突校验
- `src/lib/battleLoadoutRules.ts`
  - 技能配置规则层：职业可用池过滤、重复冲突校验、配置序列化与导入解析
- `src/components/hero/PaladinGearBoard.tsx`
  - 圣骑士装备槽位面板
- `src/components/hero/MageGearBoard.tsx`
  - 法师装备槽位面板（五角星/五边形布局）
- `src/lib/equipmentCatalog.ts`
  - 装备槽位/子类型中文映射、职业可穿戴槽位规则
- `src/state/EquipmentInventoryProvider.tsx`
  - 全局背包样本、英雄穿戴映射、装备归属查询（防跨英雄重复穿戴）
- `src/lib/equipmentSystem.ts`
  - 装备生成核心逻辑（模板抽取、Rank/Quality/词条/插槽计算）
- `src/data/equipmentTemplates.ts`
  - 装备模板与词条池配置（含饰品：戒指/项链/手镯）
- `src/data/mockData.ts`
  - 英雄基础数据 `heroes`

## 3. 标签与 URL 约定

- 路由：`/hero/:heroId`
- 标签通过 query 参数控制：`?tab=stats|gear|skills|memory`
- `HeroPage` 内部默认 tab 为 `stats`

## 4.4 装备穿戴交互（当前实现）

1. 打开任一英雄页并切到 `装备体系` 标签。
2. 点击右侧装备栏任意槽位（高亮表示当前选中槽位）。
3. 系统弹出“装备选择窗口”，展示该槽位类型在全局背包中的全部装备。
4. 鼠标悬停在装备项上会显示半透明“装备详情浮层”（基础属性、附加词条、品阶品质、插槽等）。
5. 可穿戴装备可直接点击装备；若该装备已被其他英雄穿戴则置灰不可选。
6. 点击“刷新背包”会重新生成背包样本，并自动清除失效穿戴引用。
7. 同一件装备在全局仅允许被一个英雄的一个槽位穿戴；背包页会显示“已装备：英雄名”。
8. 圣骑士手部槽位支持单手/双手同池选择；当另一手已装备时，装备双手武器会弹确认窗（确认后移除另一手装备）。

## 5. 注意事项

- 英雄页与背包页共享同一套全局背包/穿戴状态（`EquipmentInventoryProvider`），避免了页面间状态分叉。
- 队伍编队与技能槽位共享同一套全局战斗配置状态（`BattleSetupProvider`），并直接驱动战斗页。
- `MageGearBoard` 采用几何坐标计算槽位，改布局时优先改半径常量和角度，不建议手写像素偏移。
- 装备系统以 `equipmentSystem + equipmentTemplates` 为准；新增槽位或子类型时，需同步 `equipmentCatalog` 与背包筛选文案。
