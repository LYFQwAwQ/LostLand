# 04. 英雄与队伍模块

## 1. 模块范围

本模块覆盖：

1. 英雄页四个页签：属性 / 装备 / 技能 / 记忆
2. 英雄等级 / 经验 / 基础属性成长展示
3. 各职业装备槽布局
4. 技能槽位配置与导入导出
5. 记忆穿戴
6. 队伍编队
7. 队伍全量预设（编队 + 技能 + 装备 + 记忆）
8. 传奇装备穿戴（固定 5 符文槽 + 装备被动技能展示/战斗接入）

## 2. 当前最重要的架构事实

### 2.1 英雄池由 `HeroRosterProvider` 管理

- 运行时英雄池来源：`src/state/HeroRosterProvider.tsx`
- 初始生成逻辑：`src/data/heroRoster.ts`
- 酒馆签约、运行时入队/离队都走这个 Provider

### 2.2 英雄相关运行时状态分散在两个 Provider

- `BattleSetupProvider`
  - 编队
  - 每个英雄的技能槽位配置
- `EquipmentInventoryProvider`
  - 装备库存
  - 穿戴关系
  - 记忆拥有与穿戴
  - 英雄等级与经验（`heroProgressById`）
  - 传奇装备拥有状态与普通装备槽位穿戴（每英雄最多 2 件传奇）

HeroPage 只是把这两部分状态拼起来展示。

## 4. HeroPage / TeamPage 结构

### 4.1 `HeroPage`

| 页签 | 当前内容 |
| --- | --- |
| `stats` | 立绘、属性、等级、成长、原始/战斗数值切换 |
| `gear` | 装备穿戴、槽位悬浮详情、传奇装备穿戴 |
| `skills` | 技能候选、导入导出、职业与冲突校验 |
| `memory` | 记忆库存、穿戴、全局唯一校验 |

当前注意点：

- 除弥亚外，其他英雄统一走占位符立绘。
- 战斗数值不是面板静态值，而是 `battleAdapters.ts` + `battleEngine.ts` 的结果。
- 传说装备仍走普通槽位穿戴，但详情在背包页查看。

### 4.2 `TeamPage`

- 6 个槽位：前排 3、后排 3
- 支持点击分配和拖拽互换
- 预设同时保存编队、技能槽位、装备、材料/消耗品/记忆快照
- 本地存储 key：`lostland.team.presets.v2`

## 6. 待接通功能设计边界

详细设计见 `第一章占位功能设计方案.md`。本模块重点约束英雄、背包和战斗数值的归属。

### 6.1 消耗品

第一章基础版：

1. 消耗品来源至少接入 ST2 商铺、布告栏奖励或仪式奖励之一。
2. 背包页展示真实来源，不再显示 `示例库存`。
3. 战斗中使用可分阶段落地：先做战斗前携带槽位，再接入战斗运行时使用。

状态归属：

1. 消耗品库存仍归 `EquipmentInventoryProvider`。
2. 战斗携带槽位如只影响战斗配置，可归 `BattleSetupProvider`。
3. 战斗中使用次数和冷却归 `BattlePage` / `battleEngine` 运行时。

### 6.2 传说装备

第一章原则：

1. 不再默认拥有全部传说装备。
2. 第一章最多开放 1-2 件传说装备。
3. 来源必须明确，例如仪式首通、第一章结算或特定主线奖励。

状态归属：

1. 传说装备定义仍在 `src/data/config/legendaryEquipments.json`。
2. 被动技能定义仍在 `src/data/config/legendaryEquipmentSkills.json`。
3. 已解锁传说装备仍归 `EquipmentInventoryProvider`。
4. 后续建议为解锁来源补字段，方便背包显示“来自仪式 / 主线 / 章节结算”。
5. 战斗实际生效依赖 `src/lib/battleAdapters.ts` 把被动标记带入战斗模板，再由 `src/lib/battleEngine.ts` 在运行时触发。

### 6.3 记忆数值

第一章基础版：

1. 记忆继续按职业限制穿戴。
2. 每个记忆补结构化数值字段。
3. HeroPage 的“战斗数值”必须包含记忆加成。
4. `battleEngine` 必须读取同一份加成，避免页面展示和实战不一致。

第一批只支持简单加成：

1. 固定属性：`hp/mp/str/int/agi/def`
2. 百分比属性：`critRate/critDamage/lifeSteal/allRes`
3. 条件触发后置，不放第一章基础版。

## 7. 当前注意事项

1. 英雄池是 `HeroRosterProvider` 状态，不要在页面里再存副本。
2. HeroPage 的属性展示不等于战斗最终值。
3. 预设会覆盖装备与库存快照，不只是编队。
4. 记忆库存和装备库存都在同一个 Provider。
5. 传说装备已不再默认全拥有；当前仅第一章仪式奖励接通了部分解锁来源，完整章节/掉落来源仍未补齐。
