# 01. 项目与目录总览

## 1. 项目定位

`LostLand` 是一个基于 React + TypeScript + Vite 的前端原型项目，当前已经形成 5 条主链路：

1. 世界地图 -> 地区拓扑 -> 月结算 -> 回放
2. 节点入口 -> 布告栏任务 -> 战斗推进 / 提交结算
3. 英雄页 -> 装备 / 技能 / 记忆配置
4. 队伍页 -> 编队与全量预设
5. 组织基地 -> 领地扩张 -> 建筑摆放

如果要先看全局图，再看本文件，请先读：`08-架构总图与调用链图.md`。

## 2. 启动入口与 Provider 顺序

### 2.1 应用入口

- `src/main.tsx`
  - 注入全局样式 `src/styles.css`
  - 包装 Provider 顺序：
    1. `MapSystemProvider`
    2. `BattleSetupProvider`
    3. `OrganizationProvider`
    4. `EquipmentInventoryProvider`
    5. `HashRouter`
- `src/App.tsx`
  - 注册所有页面路由
- `src/components/layout/MainLayout.tsx`
  - 左侧固定导航 + 世界日志 + 资源概览 + 右侧 `Outlet`

### 2.2 当前路由树

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `/` | `WorldMapPage` | 世界地图主入口 |
| `/node/:nodeId` | `NodeHubPage` | 节点主界面 |
| `/node/:nodeId/ritual` | `RitualPage` | BL3 仪式入口，占位 |

| `/inventory` | `InventoryPage` | 背包 |
| `/hero/:heroId` | `HeroPage` | 英雄殿堂 |

## 3. 目录职责

```text
src/
  components/
    forge/                铁匠铺强化/打造复用面板（节点页 / 组织页共用）
    hero/                 职业装备面板组件
    layout/               主布局
  config/
    world/                世界层级配置（大陆/疆域/地区）
  data/
    battleSkills/         技能 JSON 分目录配置
    config/               英雄、任务、传奇等配置
    *.ts                  静态数据、模板、装载器
  lib/                    纯逻辑与规则计算
  pages/                  页面级组件
  state/                  全局 Provider
  types/                  类型定义
  styles.css              全局样式总文件
```

### 3.1 `src/pages`

页面只负责交互拼装，不应该承载新的业务真相。

### 3.2 `src/state`

项目所有运行时真相都在这里归口管理，页面通过 hook 读取和操作。

### 3.3 `src/lib`

算法、规则、适配器都放这里，便于复用和测试。

### 3.4 `src/data`

静态模板、JSON 装载、默认数据都放这里。调初始内容优先看这里，不要先改页面。

## 4. 核心调用链

### 4.1 世界地图链路

`worldHierarchy.json`
-> `src/data/worldMapData.ts`
-> `MapSystemProvider.ensureRegionLoaded`
-> `src/lib/topology.ts`
-> `WorldMapPage`

### 4.2 月结算链路

`WorldMapPage.advanceOneMonth`
-> `MapSystemProvider.advanceOneMonth`
-> `src/lib/monthlySimulation.ts`
-> 更新 `regionsById` / `worldLogs` / `lastMonthReport`
-> `WorldMapPage` 回放 UI

### 4.3 节点与任务链路

`NodeHubPage`
-> `mapRules.ts` 判断可进入口
-> `NodeActionPage`
-> `MapSystemProvider` 读取 / 更新任务
-> `EquipmentInventoryProvider` 扣材料 / 发奖励

### 4.4 英雄与队伍链路

`src/data/heroRoster.ts`
-> `src/data/mockData.ts` 生成 `heroes`
-> `HeroPage` / `TeamPage` / `BattleSetupProvider`
-> `battleAdapters.ts` 组装为战斗模板

### 4.5 战斗链路

`NodeActionPage`
-> `BattlePage`
-> `battleAdapters.ts`
-> `battleEngine.ts`
-> `EquipmentInventoryProvider.collectBattleDrops`
-> `MapSystemProvider.reportMissionBattleOutcome`

### 4.6 组织链路

`OrganizationPage`
-> `OrganizationProvider`
-> `organizationData.ts`

## 5. 当前最重要的工程边界

### 5.1 `heroes` 是静态常量，不是全局响应式英雄仓库

- 来源：`src/data/mockData.ts`
- 生成逻辑：`src/data/heroRoster.ts`
- 影响：酒馆招募、真正的英雄入队/离队、动态英雄池都不能只改页面。

### 5.2 世界地图采用 URL 选择状态

- 参数：`continent` `dominion` `region`
- 相关文件：`WorldMapPage.tsx` `worldMapData.ts`
- 改地图切换时必须同步考虑 URL 解析与回写。

### 5.3 当前只有中央大陆入口在 UI 开放

- 配置层已有全部大陆数据。
- `WorldMapPage` 会把非中央大陆选择归一化回中央大陆。
- 想重新开放，先改 `WorldMapPage`，再做联调。

## 6. 常见需求应该从哪里入手

| 需求 | 首先看的文件 |
| --- | --- |
| 地区数量、疆域关系、邻接关系 | `src/config/world/worldHierarchy.json` `src/data/worldMapData.ts` |
| 地图生成算法、节点分布、边权 | `src/lib/topology.ts` |
| 月结算规则、节点状态演化 | `src/lib/monthlySimulation.ts` |
| 节点动作开放规则 | `src/lib/mapRules.ts` |
| 布告栏任务生成与提交 | `src/lib/bulletinMissionSystem.ts` `src/data/config/bulletinMissionConfig.ts` |
| 英雄初始生成规则 | `src/data/heroRoster.ts` `src/data/config/heroGeneration.json` |
| 技能 JSON 加载与校验 | `src/data/battleSkills.ts` |
| 装备生成与评分 | `src/lib/equipmentSystem.ts` `src/lib/equipmentScoring.ts` |
| 组织地图参数 | `src/data/organizationData.ts` `src/state/OrganizationProvider.tsx` |
