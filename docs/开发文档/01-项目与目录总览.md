# 01. 项目与目录总览

## 1. 技术栈

- React 18 + TypeScript
- Vite 5
- React Router v6（当前使用 `HashRouter`）
- 图标库：`lucide-react`

## 2. 启动与构建

```bash
npm install
npm run dev
npm run build
npm run preview
```

## 3. 主入口调用链

1. `src/main.tsx`
   - 注入 `MapSystemProvider`
   - 注入 `HashRouter`
   - 渲染 `<App />`
2. `src/App.tsx`
   - 定义路由树和页面映射
3. `src/components/layout/MainLayout.tsx`
   - 左侧日志/资源/导航
   - 右侧 `<Outlet />` 承载页面

## 4. 目录结构（核心）

- `src/pages`
  - 页面级组件（地图、节点、英雄、队伍、背包、仪式）
- `src/components`
  - 可复用 UI 组件（布局、英雄装备面板）
- `src/state`
  - 全局状态与上下文（地图系统状态）
- `src/lib`
  - 核心算法和映射规则（拓扑、月结算、场强可视化、动作规则）
- `src/data`
  - 初始数据与占位业务数据（英雄、大陆、商店/任务池）
- `src/types`
  - 全局类型定义（节点、区域、回放、动作等）

## 5. 路由一览

- `/`：世界地图
- `/node/:nodeId`：节点主界面
- `/node/:nodeId/ritual`：仪式页
- `/node/:nodeId/:action`：节点功能页（detail/shop/market/...）
- `/team`：队伍页
- `/inventory`：背包页（子界面：装备/消耗品/材料）
- `/hero/:heroId`：英雄页

说明：`src/pages/LocationPage.tsx` 是旧路由兼容占位，当前统一走 `node/:nodeId`。
