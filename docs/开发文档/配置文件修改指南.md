# 配置文件修改指南

本文件只回答两个问题：

1. 某个可调参数现在在哪个文件里。
2. 改完以后会影响哪条链路。

如果新增了新的可调参数，必须把入口补到本文件。

## 1. 总原则

1. 能放配置文件的，优先不要硬编码在页面里。
2. 先确认参数属于“世界 / 英雄 / 战斗 / 背包 / 组织 / 任务”哪一类。
3. 改配置时要同时确认读取它的 `data` / `lib` / `page` 文件。
4. 如果一个参数只存在于 `lib` 常量里，说明它还不是正式配置项，改动时要在开发记录里说明影响面。

## 3. 世界地图配置

### 3.1 大陆 / 疆域 / 地区层级

文件：`src/config/world/worldHierarchy.json`

这里可以改：

- 大陆列表 `continents`
- 疆域列表 `dominions`
- 地区列表 `regions`
- 地区邻接关系 `neighbors`
- 地区选择弹窗坐标 `pickerPosition`

关键字段影响：

- `dominions[].regionIds`
  - 决定疆域包含哪些地区
- `regions[].neighbors`
  - 决定邻接地区切换与疆域内部连通图
- `regions[].seed`
  - 改地区随机种子，会直接改变拓扑生成结果
- `dominions[].baseRegionScale` / `scaleRange`
  - 控制地区节点规模
- `dominions[].complexityBase` / `complexitySwing`
  - 控制拓扑复杂度
- `dominions[].factionWeights`
  - 控制初始势力分布权重
- `dominions[].initialStrongFieldCount`
  - 控制初始强场节点数
- `dominions[].initEvolutionMonthCap`
  - 控制地区预演化月数上限
- `dominions[].pathWeightRange`
  - 控制边权范围

读取入口：`src/data/worldMapData.ts`

- 当前已实装的被动运行时口径：
  - `灰烬誓印`：开场获得 12% 最大生命的不可驱散护盾
  - `潮核低语`：每次行动后回复 6% 最大法力

  - `世界树余响`：友方获得有效治疗时，持有者获得 1 层 2 回合、每层 4% 的全伤害提升，最多 3 层
  - `封印巡守`：暗属性承伤降低 10%，并在开场获得 8% 最大生命、持续 2 回合的护盾
  - `渠誓余音`：每回合首次受伤后，获得 1 层 2 回合、每层 4% 的伤害减免，最多 3 层

- `fixedRegions[regionId].nodes[].battleConfig.countDistribution`
  - 战斗人数分布参数：`min` / `max` / `mean` / `sigma`。

- `src/data/battleUnits.ts`
  - `buildEnemyTeam(seedId, archetype, suppression, sourceNodeId)`：优先按 `sourceNodeId` 读取固定节点战斗池；缺失时回退全局池。
- `src/lib/battleAdapters.ts`
  - `buildEnemyTeamTemplates` 新增 `sourceNodeId` 透传，避免连战 seed 改变后丢失节点池绑定。

  - 任务扫描敌人池时传入真实 `node.id`，保证任务候选与固定节点敌人池一致。
