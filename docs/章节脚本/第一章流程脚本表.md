# 第一章流程脚本表（主线 / 支线 / 里程碑）

## 1. 章节定位

- 章节名称：第一章·余烬初燃
- 章节主叙事：基地在灾变后核心停摆，玩家作为临时指挥官，逐步恢复基地与周边秩序。
- 章节目标：围绕“重建核心 -> 清理周边 -> 升级核心 -> 扩建基地 -> 完全解放”建立第一章完整体验。
- 章节完成条件：
  - 完成主线 `CH1-MQ-05`（完全解放）

## 2. 章节功能开放白名单

- 第一章内开放：
  - 基地核心（状态 / 主线 / 章节追踪）
  - 第一章目标地区地图（禁止跨地区切换）
  - 节点战斗
  - 布告栏任务（接取 / 提交）
  - 商店购买（基础物资）
  - 装备穿戴
  - 酒馆招募（第一章池）
  - 组织基础建造（按主线阶段解锁）
- 第一章内关闭（统一文案：`系统受损，完成当前章节主线后恢复`）：
  - 装备强化 / 打造
  - 高级组织建筑功能（远征调度室、秘法图书馆等）
  - 非第一章地图切换
  - 复杂经济模块

## 3. 主线任务链（单目标推进）

> 主线原则：一条任务只做一件事，不做复合条件。

### CH1-MQ-01：重建核心

- 剧情摘要：
  - 基地核心停摆，工程队要求先用初始资金购买建筑材料完成应急修复。
- 完成条件（单目标）：
  - 使用初始资金完成一次“建筑材料采购”（用于核心重建）
- 完成后：
  - 基地核心恢复基础运转

### CH1-MQ-02：清理主城周边

- 剧情摘要：
  - 核心恢复后，需先清理主城周边威胁，确保补给线安全。
- 完成条件（单目标）：
  - 累计战斗胜利达到 `100` 场
- 完成后：
  - 进入核心升级阶段

### CH1-MQ-03：核心升级

- 剧情摘要：
  - 指挥部要求上交建筑材料与怪物材料，为核心完成一次正式升级。
- 完成条件（单目标）：
  - 完成一次“核心升级”提交（消耗建筑材料 + 怪物材料）
- 完成后：
  - 解锁建筑权限

### CH1-MQ-04：扩建基地

- 剧情摘要：
  - 核心升级完成后，需要建设更多功能建筑来恢复组织运转能力。
- 完成条件（单目标）：
  - 建造更多建筑（与当前建造方案保持一致）
- 完成后：
  - 解锁最终解放作战

### CH1-MQ-05（终章）：完全解放

- 剧情摘要：
  - 基地恢复、周边清剿与建设完成后，发起最终解放行动。
- 完成条件（单目标）：
  - 第一章目标地区压制值达到 `100`
- 完成表现：
  - 章节结算面板
  - 第一章总览统计（胜场 / 建造 / 压制 / 用时）
  - 第二章预告文案

## 4. 支线任务（教学与补充）

> 支线不阻塞主线，承担基础功能教学与资源补给。

### CH1-SQ-01：战地整备（穿戴教学）

- 条件：任意英雄穿戴 1 件装备
- 奖励：基础金币 + 材料包

### CH1-SQ-02：后勤采购（购买教学）

- 条件：在商店完成 1 次购买
- 奖励：补给物资

### CH1-SQ-03：临时征募（招募教学）

- 条件：在酒馆成功招募 1 名英雄
- 奖励：声望小额

### CH1-SQ-04：委托熟练（委托教学）

- 条件：累计提交委托 5 次
- 奖励：委托加速礼包（数值可调）

## 5. 里程碑系统（放置反馈）

### 压制里程碑

- `20 / 40 / 60 / 80 / 100`
- 每档奖励：金币 + 材料 + 章节广播

### 胜场里程碑

- `10 / 30 / 60 / 100`
- 每档奖励：战斗补给包 + 战报播报

### 建造里程碑

- 建造数量：`1 / 3 / 5`
- 每档奖励：建设物资

## 6. 节奏规划（第一章时长）

- 开场修复段（0-20 分钟）：
  - 主线 01（材料采购重建核心）
- 清剿熟悉段（20-70 分钟）：
  - 主线 02（100 场胜利）
- 恢复建设段（70-110 分钟）：
  - 主线 03-04（核心升级 + 扩建基地）
- 终章解放段（110-120 分钟）：
  - 主线 05（压制值 100）
- 第一章目标体验时长：
  - 约 2 小时，用于让玩家完整熟悉战斗、委托、商店、装备、建造和章节门禁的基础循环

## 7. 常驻 UI 追踪建议

- 主界面固定展示：
  - 当前主线任务（单目标进度）
  - 关键累计值：`胜场 / 压制 / 建造数`
- 任务面板分区：
  - 主线（置顶）
  - 支线（可折叠）
  - 里程碑（独立进度条组）

## 8. 失败与容错策略

- 战斗失败不扣主线进度，不做高惩罚。
- 支线可随时补做，不阻塞章节推进。
- 若长时间无主线推进，提示当前主线唯一目标。

## 9. 落地实现口径（给开发）

- 主线使用“单目标状态机”，每次仅追踪一个主线条件。
- 支线与里程碑使用累计事件计数器，不干扰主线推进。
- 建议主线事件最小集合：
  - `chapter_build_material_purchased`
  - `chapter_battle_wins`
  - `chapter_core_upgrade_submitted`
  - `chapter_building_constructed`
  - `chapter_suppression_reached`
