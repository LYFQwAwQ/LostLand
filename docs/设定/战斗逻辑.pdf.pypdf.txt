核 心 战 斗 循 环  ( B a t t l e  L o o p )
战斗逻辑采用 “ 实时跑条  + 逻辑切片 ” 模式。每一帧系统都会检查是否有单位达到行动阈值。
1 .  战 斗 准 备 阶 段  ( S e t u p  P h a s e )
在进入关卡前，系统进行一次性预结算：
属性聚合：  英雄基础属性  + 装备加成  + 技能被动加成  = 最终战斗面板（三者按顺序结算，
以此让百分比加成正常结算） 。
初始位置：  将所有单位放置在行动条的起始点
2 .  行 动 条 推 进 阶 段  ( A c t i o n  B a r  T i c k )

阈值检查：  当任意单位的    时，游戏逻辑暂停，进入该单位的
“ 行动决策时间 ” 。
C u r r e n t V a l u e ≥ 1 0 , 0 0 0
3 .  行 动 决 策 逻 辑  ( D e c i s i o n  L o g i c )  -  核 心 A I
当单位行动时，按照以下优先级进行判断：
第一步：状态检查  (Status Check)
检查是否处于 “ 冰冻 ” 、 “ 晕眩 ” 等无法行动的状态。如果是，跳过行动，清除该状态。
检查持续性伤害（中毒、燃烧等）结算。
第二步：动态权重计算  (W eight Calculation)
系统扫描该英雄当前所有可用的 主动技能 ：
1. 初始：  所有技能权重为   。1 0 0
2. 筛选：  排除掉  MP  不足或处于冷却（ CD ）中的技能。
3. 环境修正：根据当前情况对所有这些技能的权重进行修正
4. 最终随机：  基于总权重池进行一次随机抽签，决定释放哪个技能。
