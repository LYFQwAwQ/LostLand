# 装备设计

## 第1页

装备设计
1. 装备属性生成逻辑
一件装备的最终属性由三个互相独立且加乘的维度和一个基础模板构成，该系统完全由文字描
述，无需图片或表情：
1.0 基础模板
1.0.1 核心属性定义
基础属性 (T1 Stats)：定义该装备拥有的固定属性（如：攻击力、生命值） 。
Level 1 Base: 1级时的起始数值 。
Growth Rate: 每升一级增加的固定数值。
1.0.2 掉落与生成权重
基础掉落权重 (Base Weight)：决定在同级掉落池中，该装备出现的概率。
Rank 权重分布：定义该模板生成不同文字称谓（劣质、精良、卓越、完美）的概率 。
Affix (品质) 权重分布：定义生成不同颜色品质（白、绿、蓝、紫、橙、红）及其对应词条数
量的概率 。
词条池 (Affix Pool)：该装备可随机出的属性，属性数值范围及每个属性可能出现的权重 。
1.0.3 装备生成标准流程
当系统触发“生成装备”指令（如：战斗掉落、商店刷新）时，执行以下逻辑：
阶段 0：环境修正 
留出环境修正接口。
当前逻辑：修正系数全部默认为 
﻿（即不修正）。该系数未来将作用于阶段 3 和阶
段 4 的权重计算 ，卓越和精良的权重修正为初始掉落权重*M，紫，橙，红权重修正为初始
掉落权重*M。
M = 1.0
阶段 1：模板抽取
从当前环境的“掉落池”中获取所有可用模板，如战斗的掉落池，商店的刷新池等。
根据模板的 基础掉落权重 进行加权随机，选定装备模板。

1.1 基础属性 (Base Stats / T1)
由装备等级 (Level) 决定，呈现线性成长，是属性的“地板”。
计算公式： 
﻿ 
BaseStat = (Lvl1Base) + (CurrentLvl −1) × GrowthRate
1.2 增幅系数 (Rank Percentage / Rank)
决定倍率增幅，以文字称谓和视觉效果等表现其稀有度，该增幅会增幅基础属性和附加词条，不
会增幅符文插槽 。
属性公式： 
﻿ 
FinalStat = BaseStat × (1 + Rank%)

## 第3页

由装备品质 (Quality) 决定附加词条的数量，词条库包含高级属性（如暴击、穿透等）。
品质分级：
白 (Common): 0词条 | 绿 (Uncommon): 1词条
蓝 (Rare): 2词条 | 紫 (Epic): 3词条
橙 (Legendary): 4词条 | 红 (Mythic): 5词条
1.4 符文插槽

实现；

装备类型
装备按照可装备部位分为以下类型，这会影响每个装备栏是否可以穿戴该类装备：头部，护甲，
单手，双手，臂甲，腿甲，鞋，施法媒介，施法核心；
每类装备又可以具体进行细分：  
头部：重型头盔，轻型头盔  
护甲：轻甲，重甲，法袍  
单手武器：盾牌，长剑，法杖  
双手武器：巨剑，长矛  
腿甲：轻型腿甲，重型腿甲  
鞋：布鞋，重甲鞋  
施法媒介：火焰媒介  
施法核心：火焰核心
