## 4. 升级规则补充

- 建筑升级统一为“金币 + 建筑材料”双消耗。
- 当前所有建筑升级表开放到 `Lv.6`，`Lv.6 -> Lv.10` 留作后续内容。
- 铁匠铺成功率加成规则：对所有强化等级生效，最终成功率不超过“原始成功率”的 `120%`。
- 任务大厅升级加成规则：当前按等级提供任务栏上限加成（`Lv.2/4/6` 各 `+1`）。
- 基地核心升级加成规则：组织评级上限改为动态计算（基础上限 + 基地核心等级加成）。

## 5. 建造规则补充

- 建筑只能建在已揭示领地内。
- 建筑不能超出组织地图边界。
- 建筑占地不能与现有建筑重叠。
- 唯一建筑不能重复建造。
- `mana_pylon` 为非唯一建筑，可重复建造。

## 6. 功能建筑正式设计草案

详细跨模块设计见 `../开发文档/第一章占位功能设计方案.md`。

### 6.1 训练营

正式定位：让未上阵英雄通过驻训获得稳定成长。

第一章最小闭环：

1. 训练营等级决定训练槽位数和每月基础经验。
2. 玩家只能指派空闲英雄，当前编队中的英雄不能驻训。
3. 每推进 1 个世界月，驻训英雄获得训练经验。
4. 拆除训练营时自动清空槽位，已获得经验保留。

状态边界：

1. 训练槽位归 `OrganizationProvider`。
2. 英雄经验写入 `EquipmentInventoryProvider`。
3. 魔力增幅塔提供额外训练经验倍率。

### 6.2 远征调度室

正式定位：消化冗余英雄，让未上阵英雄执行离线任务获取材料和声望。

正式流程：

1. 每月生成远征任务池。
2. 玩家指派 1-3 名空闲英雄。
3. 远征占用若干世界月。
4. 结算时根据英雄等级、职业适配和任务难度计算成功率。
5. 成功发放材料、金币、声望；失败发放保底奖励。

第一章策略：

- 建议继续锁定，只显示正式锁定文案，不展示占位入口。

### 6.3 秘法图书馆

正式定位：承接技能书、记忆碎片和图鉴研究。

正式能力：

1. 技能书炼成：消耗金币、材料、研究点，产出职业技能书。
2. 记忆研究：消耗记忆碎片，解锁或升级记忆。
3. 图鉴研究：根据击败敌人和材料收集进度，解锁敌人弱点、掉落提示或小额加成。

第一章策略：

- 建议继续锁定，不开放半成品入口。

### 6.4 魔力增幅塔

正式定位：非唯一增幅建筑，提供全局小额收益。

第一章最小接入：

1. 只影响训练营经验收益。
2. 多座魔力增幅塔按等级加总倍率。
3. 暂不影响战斗经验、仪式成功率或研究速度。

后续扩展：

1. 战斗经验加成。
2. 技能书研究速度。
3. 仪式奖励或成功率修正。
