# 装备强化消耗图鉴（当前版本）

> 数据来源：`src/data/config/equipmentEnhancementConfig.ts`。

## 1. 强化规则

- 普通装备上限：`+10`
- 传说装备上限：`+15`
- 失败不掉级，消耗金币与材料
- 材料机制：同模板同种族材料链，按强化阶段切换材料类型，并随等级递增数量

## 5. 数量公式（当前实现）

- 单材料数量：`ceil((baseQuantity + growthPerLevel * (targetLevel - 1)) * stageMultiplier)`
- 金币消耗：`itemLevel * levelFactor * enhancementGrowth ^ targetLevel`
